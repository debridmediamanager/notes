# Reference

Look-up pages. Nothing here is a walkthrough. Read them when you know what you
want and need the exact name of it.

| Page | Read it when |
|---|---|
| [Configuration](config.md) | You want the exact name and default of a `config.yml` key. Every option zurg takes is on this one page. |
| [Command line](cli.md) | You want a command or a flag the binary takes. |
| [Tags](tags.md) | You are filtering a directory on `zurg_*` tags and need to know which ones get applied and why. |
| [TorBox limits](torbox-limits.md) | You are running TorBox and want the measured figures behind its throttling and how zurg paces against them. |
| [Outbound identity](outbound-identity.md) | You want to know what zurg tells the services it calls about itself. |
| [Changelog](changelog.md) | You want to know what shipped and when. |

Setting an account up for the first time is [Providers](../providers/index.md)
instead. Doing a specific job with the library is [Guides](../guides/index.md).
