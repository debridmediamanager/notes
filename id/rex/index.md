# rex

[rex](https://rex.debridmediamanager.com/id/) adalah media server untuk aplikasi resmi Plex yang tidak memiliki file apa pun. Sebuah sumber memberi tahu rex apa saja yang ada di library kamu dan menyajikan setiap file. rex men-stream file itu saat kamu menekan play. rex gratis untuk penggunaan pribadi. [Source code](https://github.com/debridmediamanager/rex)-nya bersifat publik di bawah lisensi PolyForm Noncommercial. rex berjalan di Linux macOS dan Windows serta sebagai image Docker Linux `ghcr.io/debridmediamanager/rex:nightly` ([dengan app kamu sendiri](any-source.md#run-rex-in-docker), [dengan zurg](with-zurg.md#run-rex-in-docker)).
