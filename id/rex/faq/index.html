Pertanyaan tentang rex

Jawaban singkat untuk pertanyaan yang sering muncul sebelum kamu memasang rex, dan juga setelahnya. Setiap jawaban memiliki tautan ke panduan yang berisi detailnya.

Sebelum kamu memasang

Apa itu rex?

A media server untuk aplikasi Plex resmi yang tidak menyimpan file apa pun. Aplikasi Anda akan melihat satu server Plex tambahan dengan poster, musim, riwayat tontonan, dan Continue Watching. Sebuah source memberi tahu rex apa saja yang ada di perpustakaan dan melayani setiap file. rex memutarnya langsung saat Anda menekan play. Tidak ada yang diunduh dulu.

Ini adalah server tersendiri. Ini bukan plugin Plex Media Server dan tidak memerlukannya. Jalankan di samping Plex jika Anda ingin keduanya. Install rex menjelaskan nama-nama yang dipakai, dan Move from Plex to rex membahas kedua jalurnya.

Berapa biayanya?

rex gratis untuk penggunaan pribadi, tanpa paket berbayar. Kode sumbernya bersifat publik di bawah lisensi PolyForm Noncommercial. Penggunaan komersial tidak diizinkan. Setiap build bisa dilihat di GitHub Releases, dan aplikasi Android-nya ada di rex untuk Android.

Beberapa hal di sekitarnya mungkin berbayar:

   
rex-stremio, aplikasi sendiri atau addon sebagai sumbernya Gratis
zurg nightly, sumber untuk library debrid atau Usenet Keuntungan untuk sponsor DMM
API key DMM, untuk kecocokan persis dari DMM di zurg Opsional, juga dari menjadi sponsor DMM
Image Docker rex Gratis dan publik, untuk Linux: rex di Docker

Apakah akun Plex saya berisiko?

rex bukan buatan Plex, dan Plex bisa mengambil tindakan terhadap akun yang mendaftarkannya. Gunakan akun Plex gratis baru yang khusus dibuat untuk rex, lalu bagikan ke akun Anda sendiri. Riwayat tontonan, teman, dan Plex Pass Anda tetap ada di akun Anda sendiri. Tambahkan ke akun Plex menjelaskan langkahnya. Gunakan rex dengan risiko Anda sendiri.

Aplikasi Plex mana saja yang bisa dipakai?

Seberapa jauh setiap aplikasi Plex sudah dicoba dengan rex:

Plex for Android (ponsel) Di Pixel 6: memutar, mengonversi, dan mengunduh dari penyedia Anda. Di emulator: musik dan Live TV

Plezy Di Pixel 6: memutar, dan mengunduh dari penyedia Anda
Plex HTPC Belum diuji

Dari luar rumah, hanya Plex Web yang sudah diuji.

Apakah bisa memutar 4K, HDR, dan Dolby Vision?

Ya. File diputar dalam kualitas aslinya: rex memberikan file ke aplikasi apa adanya, lalu aplikasi yang memutuskan apa yang bisa ditampilkan. Jika aplikasi tidak bisa memutar file apa adanya, rex mengonversinya, asalkan FFmpeg sudah diatur (Converting video). Konversi mengubah HDR dan Dolby Vision menjadi gambar standar (Settings, Transcoder, Enable HDR tone mapping, aktif secara default), di chip grafis jika memungkinkan. Dengan runtime OpenCL dari Intel terpasang, mesin Intel kecil (J4105) bisa mengonversi 4K HDR10 dan Dolby Vision profile 5 ke 1080p kira-kira secara real time. Tanpa FFmpeg, file yang tidak bisa diputar aplikasi akan menampilkan "This server is not powerful enough to convert video". Jika setiap judul menampilkan pesan itu di setiap perangkat, FFmpeg bukan solusinya: lihat Nothing plays.

Plex for iOS dan Dolby Vision. Plex for iOS 2026.20.0 berhenti di 0:00 saat memutar file Dolby Vision apa adanya. Real Plex Media Server yang melayani file yang sama juga macet dengan cara yang sama, jadi masalahnya ada di aplikasinya. File HDR10 dan SDR 4K bisa diputar.

Apakah saya butuh Plex Pass?

Tidak. rex memberitahu aplikasi Plex bahwa akun tempat rex terdaftar memiliki Plex Pass, jadi memutar dari luar rumah dan mengonversi video tetap berfungsi dengan akun gratis. Memutar dari luar rumah sudah diuji di Plex Web dengan akun gratis di kedua sisi; aplikasi lain belum diuji dari luar rumah. Edisi film, Dashboard, Downloads, lewati intro dan kredit, serta sisa Movie and TV capabilities juga berfungsi. Aplikasi tetap bisa menerapkan aturannya sendiri.

Bisakah saya mengunduh untuk ditonton offline?

Unduhan Downloads di aplikasi Plex sudah tersedia. rex menyiapkan unduhan di mesinnya sendiri, baik sebagai file asli maupun yang sudah dikonversi dengan FFmpeg, lalu menyimpannya di folder di sebelah rex.db sampai aplikasi mengambilnya. Akun tempat rex didaftarkan selalu bisa mengunduh. Orang yang Anda bagikan akses juga perlu izin unduh di share mereka (Share rex). Aplikasi tetap bisa menerapkan aturannya sendiri. Unduhan yang dikonversi tidak menyertakan subtitle teks. Menyimpan unduhan di ponsel dan menontonnya secara offline belum pernah diuji.

Bisakah beberapa orang memakainya, masing-masing dengan riwayatnya sendiri?

Ya. Setiap orang yang Anda bagikan rex-nya akan masuk dengan akunnya sendiri dan mendapatkan status tontonan, Continue Watching, rating, dan playlist mereka sendiri. Masing-masing bisa menyalin riwayat tontonannya dari server Plex lama (Bring your watch history). Share rex with family and friends berisi langkah-langkahnya, termasuk untuk managed users anak-anak.

Perangkat keras apa yang dibutuhkan?

Sebuah mesin yang selalu menyala, berjalan di Linux (amd64 atau arm64, glibc 2.35 atau lebih baru, jadi Ubuntu 22.04 ke atas), macOS (Intel atau Apple Silicon), atau Windows 64-bit. Di ponsel, tablet, atau kotak TV Android, rex for Android menjalankan rex dan addon-addonnya secara gratis. Untuk sponsor, aplikasi zurg+rex, server Plex di ponsel Anda, juga menghubungkan library debrid dan Usenet Anda ke rex (lihat panduan Android).

Memori: sediakan 1 GB. Pada library dengan 4.062 film dan 656 serial, rex memakai kurang dari 500 MB saat dijalankan dan sekitar 730 MB saat library sedang dijelajahi. Konversi video membutuhkan tambahan memori.

Disk: tidak perlu untuk film. rex menyimpan library-nya di rex.db. Unduhan dan gambar yang dibuat analisis (pratinjau seek, gambar bab) juga disimpan di sebelahnya, jika Anda memakainya.

Konversi: hanya dengan FFmpeg. Chip grafis membuatnya lebih cepat: film 1080p yang dikonversi di chip Intel kecil dimulai dalam sekitar 2 detik. Chip mana yang dipakai rex di setiap sistem ada di By platform: di macOS, konversi selalu dilakukan di prosesor.

Apakah rex membaca file lokal saya?

Tidak. rex tidak pernah memindai folder atau disk dan tidak butuh mount. Setiap file datang dari sumber melalui HTTP. File di disk Anda sendiri tetap bisa dipakai: sesuatu harus menyajikannya dan memberi tahu rex tentang file tersebut, seperti yang ditunjukkan di rex dengan aplikasi Anda sendiri.

Apakah bisa dipakai dengan Usenet?

Ya, lewat sumber yang membaca Usenet, seperti zurg. rex tidak pernah berbicara langsung dengan penyedia Usenet: sumber membaca file-nya dan menyajikannya ke rex seperti file lainnya. Atur zurg untuk itu dengan Usenet dan arahkan ke rex seperti di rex dengan zurg.

Apakah saya butuh zurg?

Tidak. zurg hanyalah salah satu sumber di antara yang lain. rex menerima apa pun yang berbicara dengan feed API-nya:

  • rex dengan aplikasi Anda sendiri: aplikasi apa pun yang menyajikan file melalui HTTP
  • rex dengan add-on Stremio Anda: katalog dari add-on Stremio
  • rex dengan zurg: akun debrid Anda atau Usenet
  • Membangun add-on rex: video rumahan, rekaman atau saluran, dengan program buatan Anda sendiri, serta tiga tutorial sebagai titik awal

Beberapa sumber dapat mengisi pustaka Movies dan TV yang sama.

Apakah saya perlu membuka port?

Tidak di rumah. Aplikasi Plex di jaringan rumah Anda menemukan rex tanpa perlu mengubah router. app.plex.tv juga berfungsi melalui alamat HTTPS yang diberikan rex-direct untuk rex yang sudah diklaim.

rex memerlukan alamatnya sendiri untuk menonton dari luar rumah atau untuk rumah tangga lain. Cara paling sederhana adalah satu port forward (rex-direct). Dengan IPv6 dan tanpa IPv4 publik, gunakan rex-direct over IPv6. Tailscale serve tidak memerlukan port forward pada perangkat yang menjalankan Tailscale. Use it outside your home membandingkan pilihan-pilihannya.

Apa yang tidak dilakukan rex?

Tidak ada tuner atau DVR. Musik, Live TV, dan foto memerlukan sumber yang mengirimkannya. Lihat Musik dengan rex dan Live TV dengan rex. zurg mengirim komik sebagai foto yang ditampilkan Plex Web. Radio dan stasiun mix Plexamp belum tersedia. rex tidak punya relay, jadi penggunaan dari luar rumah memerlukan alamatnya sendiri (Gunakan dari luar rumah).

Setelah kamu memasang

Kenapa aplikasi menampilkan versi Plex, dan "Check for Updates"?

rex memperkenalkan diri ke aplikasi dan ke plex.tv sebagai Plex Media Server, jadi aplikasi menampilkan nomor versi Plex Media Server. Nomor itu bukan milik rex. Check for Updates selalu menjawab bahwa server sudah terbaru: rex tidak pernah memperbarui dirinya sendiri. Untuk memperbarui rex, unduh nightly yang lebih baru seperti di Updating.

Kenapa browser saya di port 32400/web tidak membuka pustaka?

rex tidak punya web app sendiri. Membuka http://<rex's LAN IP>:32400/web akan menampilkan halaman status singkat. Tontonlah di aplikasi Plex atau di browser lewat app.plex.tv.

Data apa saja yang keluar dari komputer saya?

  • plex.tv, saat mulai dan sekali sehari, terdaftar atau tidak: id, nama, dan versi server, untuk membaca daftar rilis publik Plex dan mencari nomor versi terbaru.
  • plex.tv, setelah terdaftar di akun Plex: klaim, alamat server (alamat LAN dan alamat HTTPS-nya), dan nama library-nya.
  • Layanan metadata Plex, setelah terdaftar: id setiap judul, untuk mendapatkan nama, poster, ringkasan, dan episodenya. Pencarian subtitle, lewat Search Subtitles atau pengaturan subtitle otomatis seseorang, mengirim nama dan sidik jari file.
  • Host artwork, saat sebuah aplikasi menampilkannya: permintaan untuk poster dan gambar yang disebut sumber-sumbermu.
  • DMM, untuk rex-direct, setelah terdaftar dan kemudian setiap 6 jam: id server, token-nya di akun Plex, dan IP LAN-nya. DMM memeriksa ke plex.tv bahwa server itu milikmu, melihat IP publik-mu, dan mengarahkan nama rex-direct-mu ke IP itu dan ke IP LAN. Jika mesin punya alamat IPv6 global, rex juga mengirimkannya, satu menit setelah mulai (atau setelah diklaim) dan kemudian setiap 6 jam, dan setiap kali DMM terhubung ke sana untuk memastikan alamat itu mencapai server yang sama. Matikan dengan REX_DIRECT_URL=off.
  • Sumber-sumbermu, saat kamu memutar atau menghapus: permintaan untuk file yang kamu putar, dan penghapusan (di bawah).
  • Server Plex lamamu, hanya saat kamu membawa riwayat tontonanmu: permintaan untuk riwayat tontonanmu.
  • Webhook, hanya jika kamu mengatur beberapa: event, ke alamat yang kamu atur.

rex tidak bertanya kepada siapa pun apa itu sebuah rilis: sumbernya yang memutuskan dan memberi tahu rex. zurg, misalnya, bertanya kepada DMM (Mengapa DMM menempatkan file).

Apakah menghapus di aplikasi Plex juga menghapus file-nya?

Ya. Menghapus film atau episode di aplikasi Plex, saat masuk dengan akun tempat rex terdaftar, akan menghapus file-nya di sumber, sama seperti server Plex menghapus file dari disknya. Sumber di akun debrid, seperti zurg, akan menghapusnya di sana. Jika sumber menolak, judul tetap ada dan aplikasi akan memberi tahu bahwa judul tidak bisa dihapus. Orang yang kamu bagikan akses tidak bisa menghapus. Menghapus di aplikasi Plex menjelaskan cara mematikannya.

Tidak ada yang bisa diputar, atau semua aplikasi bilang perangkatnya tidak cukup kuat

Lihat log rex tepat setelah kamu menekan Play. upstream failed atau 502 di sana berarti rex tidak bisa menjangkau sumber kamu di alamat yang diberikan sumber tersebut, dan memasang FFmpeg tidak akan memperbaikinya. Penyebab yang paling umum adalah zurg di Docker Desktop pada Windows atau macOS. Baris upstream failed di rex dengan zurg atau rex dengan aplikasi sendiri memeriksa alamat tersebut dan memberi tahu apa yang harus diubah. Jika hanya sebagian file yang gagal, sering kali hanya di web browser, berarti perangkat tidak bisa memutarnya apa adanya: atur Konversi video.

Sebuah judul salah dicocokkan. Bagaimana cara memperbaikinya?

Sumber yang menentukan apa isi setiap file, dan rex menampilkan judul tersebut. Masuk dengan akun tempat rex terdaftar, lalu gunakan Fix Match: rex menyimpan pilihan Anda, dan sebuah sumber dapat membacanya kembali untuk menyimpannya sebagai pencocokan untuk rilis tersebut, seperti yang dilakukan zurg (Mengapa DMM menempatkan file).

Di mana saya bisa mendapatkan bantuan?

Mendapatkan bantuan menjelaskan di mana harus bertanya dan apa saja yang perlu disertakan: forum rex-support di Discord, dan bantuan jarak jauh untuk sponsor.
