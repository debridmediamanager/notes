# 参考 {#reference}

查询页面。这里没有任何教程。当你已经知道自己要什么、需要确切的名称时再来看。

| 页面 | 何时阅读 |
|---|---|
| [配置](config.md) | 当你需要 `config.yml` 某个键的确切名称和默认值时。zurg 接受的每个选项都列在这一页上。 |
| [命令行](cli.md) | 当你需要查找某个命令或可执行文件支持的参数时。 |
| [标签](tags.md) | 当你要按 `zurg_*` 标签筛选目录，并需要知道哪些标签会被应用以及原因时。 |
| [对外身份](outbound-identity.md) | 当你想知道 zurg 向它所调用的服务透露了哪些关于自身的信息时。 |
| [MCP 服务器](mcp.md) | 当你想让 AI 智能体来操控 zurg，并需要了解它暴露的工具集以及每个工具集可以做什么时。 |
| [更新日志](changelog.md) | 当你想知道哪些功能何时发布时。 |

提供商相关的内容已经移到别处。TorBox 的限制和内置的新闻服务器位于 [提供商](../providers/index.md) 下。首次设置账户也在那里进行。要用这个库完成某项具体任务，请看 [指南](../guides/index.md)。
