赞助能给你带来什么

DMM 免费使用。赞助费用用于支付托管费用，并让 zurg 和 rex 持续开发。本页列出了所有赞助福利以及设置方法。

在 gatekeeper 上赞助。登录后可以看到你的 DMM API 密钥。点击 Open DMM with this key 可在该浏览器中关联密钥。在其他要求填写密钥的服务中，添加同一个密钥。请妥善保管，它的作用和密码一样。

福利跟随赞助状态。赞助结束后，DMM 会在下一次请求时停止提供这些福利。你已经安装的 Jellyfin 和 Emby 插件仍然可以继续使用，但新的下载和更新将停止。Gatekeeper 会在下一次检查时撤销 zurg 访问权限以及 Discord 角色。Reset key 会让所有位置的旧密钥同时失效。

rex

rex 免费使用，无需赞助，Android 上也是如此：rex for Android 可以在手机或电视盒子上运行 rex 及其插件。配合密钥使用时，rex-stremio 会添加 DMM 已经有探测结果的种子对应的 debrid 流，几秒内即可完成，无需逐个探测。把密钥粘贴到 rex-stremio 的 DMM 栏中即可。除非你关闭此功能，否则它会与 DMM 共享种子文件的探测结果。

免费也能获得

在 DMM 的请求板上完成请求。每完成 10 个请求可获得 7 天的 DMM 权益。同一个人每天只有一次完成会计入。从请求板上的免费 gatekeeper 账户中获取密钥,即可领取这些时长。

获得的时长只会开通上文提到的 DMM 表格,不会开通 zurg 每夜版、源代码、Discord 身份组、远程帮助或 Android 应用。这些需要付费赞助。dmm_api_key 相关功能还需要每夜版。

遇到问题?请到 Discord 上的 dmm-support 论坛提问。
