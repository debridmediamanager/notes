从你想观看的应用开始。 你不需要每个组件都装。DMM 帮你挑选版本。提供商提供文件。zurg 可以把这些文件变成共享库。rex 把库呈现给 Plex 类应用。有些路线会跳过其中某个组件。

这张地图涵盖了 2026 年 11 月 10 日 检查过的受支持路线。它也包括能省掉某一步的外部替代方案。第三方插件和设备仍可能有所不同。请按照链接的指南及其测试过的限制来操作。

选择文件来源

索引器用来查找资源。种子或 NZB 描述如何获取资源。提供商提供实际的数据。播放器负责解码。访问其中一个并不代表包含其他的。

当你希望 TorBox 负责下载和修复时，请选择 TorBox hosted NZBs。DMM 会把 NZB 发送到那里。当前的 zurg 每夜构建版使用提供方类型 torbox_nzb，并接受来自 watch directory 和 SABnzbd 接口的 NZB。TorBox hosted Usenet 中有对应的 zurg 设置说明。缓存未命中时，必须先下载完成才能播放。下载与种子共用名额。已保留的文件可能会过期，zurg 也不保证会重新获取过期的版本。请保留 NZB，以便之后再次获取。

当你希望 zurg 通过你自己的新闻服务器账户读取内容（包括备用或区块账户）时，请选择直接 Usenet。它使用 nzb 加 NNTP 凭据。TorBox 的新闻服务器登录也属于这一类。它与 TorBox hosted NZBs 是分开的。请参阅 TorBox NNTP 和它的套餐。

一个 zurg 实例只能使用 nzb 或 torbox_nzb 其中之一。 两者都会占用 NZB watch directory。若要同时运行，请使用单独的实例和工作目录。如果两者都设置了 dmm_api_key，请在其中一个上关闭 dmm-wanted 来源，否则每个 Wanted 标题都会被获取两次。两者都可以与种子提供方并存。zurg 的 Stremio 插件会把它选中的版本提交到该实例所配置的任一 NZB 账户。使用 torbox_nzb 时，只有 TorBox 已经持有的版本能在插件的等待时间内开始，并且只有在没有其他 NZB 提交正在等待时才会如此。

当你希望版本进入你的 RD 库时，请选择 DMM → Real-Debrid。这是一种托管式传输，有队列和配额限制。未缓存的任务需要一些时间。它并不会为 Real-Debrid 或其他 debrid 提供方添加原生 NNTP 支持。DMM 的结果和 Transfers page 会显示进度。

Easynews 的 Watch 和 Cast 可以播放其 HTTP 文件，Download NZB 则会保存该版本的 NZB。Send to zurg 会把该 NZB 放入你的赞助者 Wanted 列表。这需要已配置 NZB 后端。在 DMM 中登录 Easynews 并不会配置 zurg 的 NZB 账户。

HTTP 链接怎么办？

DMM 的 TorBox Add 对话框可以把直接的 HTTP(S) 链接当作网页下载来添加。zurg 会在 __downloads__ 中显示这些内容。不过，那里的条目不会自动变成已识别的 rex 库条目。Real-Debrid 的无限制下载也可能出现在那里。DMM 的 TorBox Cast 会包含已完成的网页下载、Usenet 下载和种子。如果网页需要登录、链接会过期、有 DRM，或者用了自己的播放器，可能还需要其他集成方式。

rex 通过其 feed API 支持可流式播放的 HTTP(S) 媒体。 来源或插件会发送媒体地址和元数据，然后 rex 让它们可以在 Plex 应用中播放。文件服务器和 feed 生产者可以是分开的。不需要 zurg 或 debrid 账户。rex-stremio 可以为兼容的 Stremio 插件实现这一点。原始磁力链接和仅限种子的流媒体无法使用。HLS 需要 rex 的 FFmpeg 设置。rex 使用来源提供的标识。

决定标题如何添加

获取内容和播放是两件独立的事。你可以改变请求影片的方式，而无需更换你观看所用的应用。

你如何选择影片 路径 为什么用它？
精确选择某个发布版本 DMM 搜索/库 → 提供商；或一个 NZB → 你所选的 NZB 后端 由你自己掌控版本、大小和发布组
点击 Want，或订阅 Trakt/MDBList 列表 DMM Wanted → zurg 获取 无需运行 Sonarr/Radarr 即可自动获取电影和新剧集；需要赞助。
家人通过 Seerr/Overseerr/Jellyseerr 提出请求 通过 DMM 使用 Seerr → Wanted → zurg 无需 arr 服务器即可使用熟悉的请求界面；需要赞助。Seerr 需要连接到 Plex、Jellyfin 或 Emby 服务器才能设置。
已经有 Plex 观看列表或请求系统 zurg 获取 保留现有的请求来源；配置其搜索和提供商目标。
想在 Sonarr/Radarr 中进行详细监控和质量配置 DMM 或你的索引器 → arr → zurg 下载客户端接口 → 库 保留 arr 的决策和导入流程；需要更多服务和路径设置。
只想在按下播放时再选择 DMM Cast/Kodi、其他流媒体插件，或 zurg 的 Stremio 搜索 无需预先建立所有影片的受管库。

对于推荐的 DMM + zurg arr 路径，DMM 是索引器，zurg 是下载客户端。DMM 提供 Torznab 和 Newznab。两者都需要有效的赞助。Prowlarr 是可选的。zurg 提供 qBittorrent 和 SABnzbd 接口。你不需要在 zurg 旁边再安装那些下载应用。zurg 也可以为 arr 搜索。

如果你想要完整的本地副本，请从提供商或 zurg 下载文件。你也可以使用播放器的离线下载功能，或普通下载器加磁盘库。请检查配额，然后在无网络时播放已保存的文件。zurg 虚拟文件、.strm 链接和本地 debrid 目录都不是离线副本。本地目录只保存记录。播放仍然依赖提供商。

安装前需要权衡的关键点

问题 什么情况会改变你的选择
另一台机器必须一直开着吗？ 托管的 Cast/Kodi 路线、供应商 WebDAV 和 DMM Watch 不需要你自己的服务器。zurg、rex、rex-stremio 和媒体服务器插件在你观看时确实需要它们的主机运行。在 Android 设备上，zurg+rex 会运行 zurg 和 rex，而 rex for Android 会运行 rex 及其插件，包括 Stremio 插件；rex-stremio 和媒体服务器插件仍然需要普通主机。租用或托管的主机只改变由谁来运行它，并不改变底层路线。
我的电视能播放这个文件吗？ WebDAV 和插件路线取决于播放器的编解码器、音频和字幕支持。zurg 只负责传输字节，它不是视频转码器。Plex Media Server、Jellyfin、Emby 或带 FFmpeg 的 rex 可以在需要时进行转码，但这取决于合适的硬件以及服务器或应用的能力。
需要多少磁盘空间？ 流式播放避免了把整个收藏库都存下来。但要为数据库、封面图、缓存，以及任何修复、转码或离线下载的工作预留空间。“不需要先完整下载”并不等于零磁盘占用。
谁承担带宽？ 供应商的流量配额依然适用。服务器代理会转发播放流量，并占用它的上行带宽；直接播放则把连接转移到观看者那里。媒体库分析也可能读取远程文件。
在外面能用吗？ 托管的插件可以避免暴露你自己的服务器。自托管服务需要一个可以安全访问的地址；仅有局域网地址在外面是无法使用的。参见 rex 远程访问 和 Stremio HTTPS 指南。
家人能同时使用吗？ 请检查你供应商的 IP/并发规则，以及服务器的共享方式。Real-Debrid 的使用必须保持在同一个公网 IP 上；即使是由中央库提供的直链，如果发给不同住户，也可能违反这一规则。在没有弄清下载来源之前，不要启用重定向。
我要为什么付费？ 请把供应商订阅、索引器访问、DMM 赞助、托管服务，以及播放器/服务器的购买分开看待。DMM 的基础网站以及个人使用的 rex 是免费的；rex for Android 也是免费的。zurg+rex 会把你的 debrid 和 Usenet 库同时接入 Android 上的 rex，它只面向赞助者。当前的 zurg 每日构建版和 DMM 的插件分发是赞助者权益；Wanted 以及 DMM 的索引器 API 也需要赞助。rex-stremio 不需要赞助。赞助能带来什么 列出了所有权益以及在哪里设置。
目录里有条目就一定能播放吗？ 不能。插件目录只描述影片名称；云端文件可能过期；种子可能没有来源；Usenet 文章可能缺失。请选择你能接受其失败和等待方式的路线。

兼容的服务器客户端也可以是第三方应用。Infuse 可以连接 Plex、Emby 和 Jellyfin。你可能不需要单独挂载 zurg。请同时检查插件和客户端。

Infuse 支持 WebDAV 和其他网络共享。.strm 文件会给 Kodi 等兼容播放器提供一个 URL。它并不是通用的挂载替代方案。请检查客户端，并注意其代理和故障切换行为有所不同。不要把 .strm 用作常规的 Plex Media Server 设置。

还有一个旧版免费 zurg 发行版。它只支持 Real-Debrid，并使用不同的配置格式。这里介绍的多供应商 Usenet 和 Android 路线使用的是赞助者每日构建版。

rex 有它自己的兼容性边界。 它是一个独立的 Plex 应用服务器，不是 Plex Media Server，也不是 Plex 插件。关于经过测试的设备、远程转码使用以及全新账号的建议，请查看其 FAQ。传统的 Plex 服务器可以与 rex 并行运行。

可能改变路线的需求

我还需要… 该选择或检查什么
本地文件和云端影片一起用 保留你现有的 Plex/Jellyfin/Emby 服务器，再添加挂载或对应的插件。rex 可以合并多个 feed 来源，包括用于本地文件的 HTTP 来源，但这些文件仍然需要它们自己的元数据。
自动字幕文件 播放器自带的或视频内嵌的字幕可能就够用了。如果用 arr 工作流，Bazarr 配合 zurg 会把本地字幕文件写在虚拟视频旁边；这些旁挂字幕不会出现在 DMM Cast、Kodi 插件、DMM Watch 或 zurg 的 Stremio 插件里；但它们能通过 WebDAV 来源被 Kodi 读取。rex 也有不需要 Bazarr 的 Search Subtitles 功能。
换服务器时保留观看记录 切换前先阅读 从 Plex 迁移 和 导入观看状态；更换来源并不会自动迁移每个应用的观看记录。
与拥有自己账号的人分享选择 DMM hashlist 可以分享资源选择，让别人添加到他们自己的账号里。它们不会传输你的凭据，也不会托管播放。分享服务器是另一种方式，要遵守其分享和服务商的规则。
带宽有限的 VPS 或远程主机 检查该路由是代理还是重定向播放。rex 直接下载设置说明了相关选项；重定向会改变下载器的公网 IP，还可能暴露服务商的 URL。

其他媒体和已有的搭建

  • 音乐： DMM Music 提供 Real-Debrid 的网页播放和下载。rex 音乐来源 可以供 Plexamp 和支持的 Plex 应用使用。来源可以是专为音乐配置的插件或 zurg。别以为电影/剧集插件也会提供音乐。
  • 直播电视： rex 的直播电视路线 在文档中列出的应用里提供频道和节目指南。而 rex-stremio 的直播频道会形成一个频道库，这和节目指南界面并不是一回事。使用前先确认来源是否可用。rex 不提供 DVR 录制功能。
  • 家庭视频、录像和照片： 用你现有的媒体服务器，或者一个你自己掌控的 rex 来源。家庭视频教程 演示的就是后一种做法。zurg 也可以把漫画作为照片提供给 rex，不过各应用的支持情况不同。
  • 已经在用的 Kodi/Stremio 插件： 如果你现有的插件已经提供了你想要的体验，就保留它。DMM 可以作为你选择和管理资源的地方，而不必替换你的播放器。各插件对供应商、Usenet 和 HTTP 的支持程度不一，DMM 这条路线并不保证所有插件都兼容。
  • 已安装其他 debrid 挂载/下载工具： 切换前请先看看 迁移选项。能正常运行的配置，不需要仅仅因为“已经存在”就再加一层。
  • 正在开发的原生应用： Usenet TV 还不是已正式发布、可在应用商店获取的方案，这里不作推荐。Yomu TV 是另一个独立的阅读/有声书项目，不属于这套电影/剧集方案的路线。以上两者对于前面列出的路线来说都不是必需的。

五种常见的起步方案

  1. “我有 Stremio 和 RD。” 先从 DMM Cast 开始。只有当你需要共享库、自动化或其他需要它的客户端时，再添加 zurg。

  2. “我有 TorBox Pro，想用那篇帖子里的 NZB。” 通过 DMM 把 NZB 发送到 TorBox。想在 Stremio 里观看就用 TorBox Cast，想在 Kodi 里观看就用 Kodi 插件，或者用 zurg 的托管 NZB 后端，为你选择的库/播放器路线提供内容。

  3. “我已经有 Jellyfin。” 先从你所用服务商的插件开始。当你需要 zurg 的共享文件系统、自动化或更广泛的后端功能时，再选择单独的 zurg。

  4. “我想要 Plex 应用、不需要挂载，并且保留现有插件。” 使用 rex-stremio 配合 rex。如果你想输出的是你自己托管的 debrid/Usenet 库，就改用 zurg 作为源。两个源都可以为同一个 rex 提供内容。

  5. “我有 Usenet 账户，想用 Sonarr/Radarr。” 使用 DMM Newznab 或你现有的索引器、zurg 的 NZB/SABnzbd 路线，以及第一张表中的某条播放路线。如果需要永久保存的本地文件，请选择普通下载器，或明确保存完整副本；仅有虚拟导入并不是离线文件。

还是拿不准？告诉我们你的设备或播放器、现有账户、主机能否一直开机，以及你想要按需播放还是自动同步库。这些答案通常能决定该走哪条路线。获取帮助 说明了可以在哪里提问。
