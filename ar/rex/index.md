# rex

[rex](https://rex.debridmediamanager.com/ar/) خادم وسائط للتطبيقات الرسمية لـ Plex، ولا يملك أي ملفات. يخبره المصدر بما في مكتبتك ويقدّم كل ملف، ويبث rex الملف عندما تضغط على تشغيل. rex مجاني للاستخدام الشخصي. [الكود المصدري](https://github.com/debridmediamanager/rex) متاح للعموم بموجب ترخيص PolyForm Noncommercial. يعمل على Linux وmacOS وWindows، وكصورة Docker لنظام Linux باسم `ghcr.io/debridmediamanager/rex:nightly` ([مع تطبيقك الخاص](any-source.md#run-rex-in-docker)، [مع zurg](with-zurg.md#run-rex-in-docker)).

- [rex لنظام Android](https://github.com/debridmediamanager/rex-android) يشغّل rex وإضافاته على هاتف أو جهاز لوحي أو صندوق TV، دون حاجة إلى حاسوب. وهو مجاني
- [أسئلة حول rex](faq.md) يجيب عمّا يجب معرفته قبل التثبيت
- [rex مع تطبيقك الخاص](any-source.md) يعدّ مصدرًا يقدّم الملفات عبر HTTP ويتحدث واجهة feed API الخاصة بـ rex
- [rex مع إضافات Stremio](stremio.md) يملأ rex عبر rex-stremio. وهو مجاني ولا يحتاج إلى رعاية
- [rex مع zurg](with-zurg.md) يملأ rex من حساب debrid أو من Usenet عبر zurg
- [البث المباشر مع rex](live-tv.md) يضيف القنوات المباشرة ودليل البرامج عبر rex-live-sports
- [الموسيقى مع rex](music.md) يضيف مكتبة موسيقى لـ Plexamp وتطبيقات Plex المدعومة
- [الانتقال من Plex إلى rex](from-plex.md) يشغّل rex بجانب Plex أو بدلًا منه
- [شارك rex مع العائلة والأصدقاء](sharing.md) يدعو الأشخاص الذين تشاهد معهم

- [دروس الإضافات](addon-home-videos.md) لبناء إضافات كاملة للفيديوهات المنزلية أو الموسيقى أو IPTV في ملف Python واحد
