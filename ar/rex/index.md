# rex

[rex](https://rex.debridmediamanager.com/ar/) هو خادم وسائط للتطبيقات الرسمية لـ Plex، ولا يملك أي ملفات. يخبره المصدر بما هو موجود في مكتبتك ويقدّم كل ملف. يبث rex الملف عند الضغط على تشغيل. rex مجاني للاستخدام الشخصي. [الكود المصدري](https://github.com/debridmediamanager/rex) له متاح للعموم بموجب رخصة PolyForm Noncommercial. يعمل على Linux وmacOS وWindows، وكصورة Docker لنظام Linux باسم `ghcr.io/debridmediamanager/rex:nightly` ([مع تطبيقك الخاص](any-source.md#run-rex-in-docker)، [مع zurg](with-zurg.md#run-rex-in-docker)).

- [rex لأجهزة Android](android.md) يشغّل rex وإضافاته على الهاتف أو الجهاز اللوحي أو صندوق التلفاز، دون الحاجة إلى حاسوب. وهو مجاني
- [أسئلة حول rex](faq.md) يجيب عمّا يجب أن تعرفه قبل التثبيت
- [rex مع تطبيقك الخاص](any-source.md) يعدّ مصدرًا يقدّم الملفات عبر HTTP ويتحدث بواجهة التغذية الخاصة بـ rex
- [rex مع إضافات Stremio الخاصة بك](stremio.md) يملأ rex عبر rex-stremio. وهو مجاني ولا يحتاج إلى رعاية
