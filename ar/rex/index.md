# rex

[rex](https://rex.debridmediamanager.com/ar/) هو خادم وسائط للتطبيقات الرسمية لـ Plex، ولا يملك أي ملفات. المصدر يخبر rex بما هو موجود في مكتبتك ويقدم كل ملف. يبثّ rex الملف عندما تضغط على تشغيل. rex مجاني للاستخدام الشخصي. [الكود المصدري](https://github.com/debridmediamanager/rex) متاح للعموم تحت ترخيص PolyForm Noncommercial. يعمل على Linux وmacOS وWindows، وكصورة Docker لنظام Linux باسم `ghcr.io/debridmediamanager/rex:nightly` ([مع تطبيقك الخاص](any-source.md#run-rex-in-docker)، [مع zurg](with-zurg.md#run-rex-in-docker)).
