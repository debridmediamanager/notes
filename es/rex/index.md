# rex

[rex](https://rex.debridmediamanager.com/es/) es un servidor multimedia para las apps oficiales de Plex que no posee ningún archivo. Una fuente le indica qué hay en tu biblioteca y sirve cada archivo. rex transmite ese archivo cuando pulsas reproducir. rex es gratuito para uso personal. Su [código fuente](https://github.com/debridmediamanager/rex) es público bajo la licencia PolyForm Noncommercial. Funciona en Linux, macOS y Windows, y como imagen Docker de Linux `ghcr.io/debridmediamanager/rex:nightly` ([con tu propia app](any-source.md#run-rex-in-docker), [con zurg](with-zurg.md#run-rex-in-docker)).
