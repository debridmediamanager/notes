# rex

[rex](https://rex.debridmediamanager.com/pt/) é um servidor de mídia para os aplicativos oficiais do Plex que não guarda nenhum arquivo. Uma fonte informa ao rex o que existe na sua biblioteca e serve cada arquivo. O rex transmite esse arquivo quando você aperta play. O rex é gratuito para uso pessoal. O [código-fonte](https://github.com/debridmediamanager/rex) é público sob a licença PolyForm Noncommercial. Ele roda no Linux, macOS e Windows, e também como a imagem Docker para Linux `ghcr.io/debridmediamanager/rex:nightly` ([com seu próprio app](any-source.md#run-rex-in-docker), [com zurg](with-zurg.md#run-rex-in-docker)).
