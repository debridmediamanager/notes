zurg

zurgは、デバッドのアカウントとUsenetのライブラリを1つの仮想フォルダにまとめます。ローカルに動画を保存することはありません。プレーヤーが要求するまで何も取得されないため、60 GBのリミックス動画がローカルのディスクを60 GB使うことはありません。

同じライブラリを見る4つの方法:

エンドポイント 用途
/dav/ WebDAV。rcloneがマウントするもの
/http/ HTMLのディレクトリブラウザ
/infuse/ Infuseの癖に合わせたWebDAVのバリアント
/strm/ .strmファイル内の署名付きURL。マウントではなくURLを求めるプレーヤー向け

セットアップ

zurg を自分のマシンで動かしてみましょう。

  • Linux — FUSE 3 と systemd による自動起動
  • Docker — ホストから見えるマウントを持つ Linux ホスト
  • macOS — macFUSE と launchd による自動起動
  • Windows — WinFsp とドライブレターのタスク

プロバイダー

zurg をアカウントに接続します。 各ページでは、認証情報と config.yml の設定項目を説明しています。 例はすべて Docker を使っています。バイナリでインストールする場合も、設定項目は同じです。 コマンドについては Setup を参照してください。

ページ 違う点
Real-Debrid ファイル単位の選択、__downloads__、CDN ホストの選択、.strm 用の別トークン
TorBox ライブラリ更新ごとのリクエストは 1 回。帯域幅ではなく、同時アクティブスロットの上限で制限される
AllDebrid ファイル一覧は専用のエンドポイントから届くため、最初のスキャンでは少しずつ埋まっていく
Premiumize 完了した転送と、クラウドに残ったファイルを、フォルダ構成ごと扱う
Debrid-Link seedbox の一覧にはすべてのファイルが含まれ、キャッシュチェックはない
Offcloud サイズは配信サーバーで確認し、フォルダパスはキャッシュされたメタデータから取得する
Usenet プロバイダー項目としての nzb タイプ。トークンは不要で、代わりに監視ディレクトリを使う
TorBox limits TorBox のスロットリングの背景にある実測値と、zurg がそれに合わせてどうペース調整するか
TorBox ニュースサーバー · ElfHosted ニュースサーバー 同梱の Usenet アカウントが通信上どういうものか

共通ページでは、Docker でアカウントを追加する 3 つの方法と、設定ローダーが適用するルールを説明しています。

ガイド

  • Usenet — nzb バックエンドのエンドツーエンドの手順です。ニュースアカウント、NZB、マウント、Plex まで扱います
  • Sonarr & Radarr for Usenet — *arr は zurg の回答を SABnzbd として受け取るので、インポートはダウンロードではなく名前の変更で済みます
  • Sonarr & Radarr for torrents — 同じ内容ですが、zurg が qBittorrent として応答します。Prowlarr も対象です
  • zurg searches for Sonarr & Radarr。Radarr と Sonarr はリストを保持し、リリースの検索と配置は zurg が行います。どちらにもインデクサーやダウンロードクライアントは不要です
  • __magic__ — レイアウトが保存される唯一のディレクトリで、そのため自分で整理できます。ライブラリはタイトルごとに Kodi と Plex 用に整理されます
  • Renaming — ライブラリのどこでもリリースやファイルの名前を変更できます。移動は拒否され、その理由がページに表示されます
  • Plex — zurg が Plex トークンで何をするか、そして意図的に何をしないか
  • Jellyfin — Jellyfin 向けの同じ内容です
  • rex with zurg — ファイルを持たず、debrid アカウントから zurg が中身を入れる Plex アプリ向けメディアサーバーです。詳しくは rex をご覧ください
  • The Stremio addon — 自分のインデクサーを検索し、Usenet バックエンドから直接再生する Stremio です
  • Watchlist and Seerr は、自分のインデクサー経由で依頼したものを取得します
  • Plex watchlist は、その Plex 側の機能です
  • DMM wanted list は、DMM で Want を押したものを取得します。ほかに設定は必要ありません
  • Local libraries は、共有のリリース一覧を自分のアカウント経由で再生します
  • Android と Google TV は、スマートフォンや TV ボックスでライブラリ全体を動かします

移行

リファレンス

  • Configuration — config.yml のすべてのオプション
  • Command line では zurg のバイナリが受け付けるすべてのコマンドとフラグを一覧できます
  • Outbound identity では、zurg が呼び出すサービスに自分自身について何を伝えるかを説明しています
  • MCP server では、AI エージェントが Model Context Protocol 経由で zurg を操作する方法を説明しています
  • Tags — torrent にどのタグが付けられ、その理由は何か
  • Changelog — いつ何が変わったか
