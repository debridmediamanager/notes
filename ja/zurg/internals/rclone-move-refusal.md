# 拒否された移動の後に空のインポートが発生する {#empty-imports-after-a-refused-move}

rclone 1.72.0、ローカル優先の union、VFS full caching、そして Sonarr 4.0.19.2979 が使う .NET 6 の `File.Move(source, destination)` で再現しました。

バックエンドが MOVE を拒否すると、rclone の `vfs.File.rename` は、ファイルのディレクトリと名前を試みた移動先のままにしてしまいます。すると .NET はコピーにフォールバックします。コピー先を作成すると空の VFS キャッシュエントリができ、コピー元を開くとその同じエントリに到達するため、コピーは EOF を読んで成功と報告してしまいます。再現テストでは 4096 バイトを期待していましたが、受け取ったのは 0 バイトでした。WebDAV の拒否応答を 409 から 422 に変えても、結果は変わりませんでした。

`scripts/patches/rclone-v1.72.0-rename.patch` のパッチは、即時の rename が失敗したときに元のディレクトリと名前を復元します。アップストリームの VFS リグレッションテストも含まれています。マウントテストは、フェイクのアーカイブを使い、プロバイダーの認証情報なしで、WebDAV、union、FUSE、.NET の経路全体を検証します。その破損判定は、フィクスチャのバイトがまだ読める状態で注入されます。.NET はそれらのバイトを正常にコピーしてもかまいませんが、空のファイルに変えてはいけません。

新しいバイナリは、インストール済みのものと並べてビルドします:

```sh
./scripts/build-rclone-move-fix.sh /absolute/path/to/rclone-fixed
RCLONE_TEST_BIN=/absolute/path/to/rclone-fixed ./integration/magic_move_refusal.sh
```

ビルドはアップストリームのコミット `38ab3dd5b1df946aecf5bd085c671c86f46f68eb`（1.72.0）に固定されています。ビルド前に VFS の rename テストを実行します。マウントテストには Linux FUSE と Docker が必要です。または、`integration/dotnet-move-probe` からビルドした自己完結型の `DOTNET_MOVE_PROBE_BIN` を使います。未修正のバイナリに対しては、意図的に失敗します。`make integration-test` にはこのチェックが含まれます。スイートを実行するときは、`RCLONE_TEST_BIN` と `RCLONE_BIN` を修正版のバイナリに向けてください。

インストールには、デプロイの通常のメディアサーバー向けガードを使ってマウントを再起動する必要があります。ロールバックできるように、以前のバイナリは残しておいてください。union のローカルのアップストリームにある既存の空ファイルは、マウントの再起動後も残ります。そこでは、空のインポート成果物であることが確認できたものだけを残す、または削除してください。再起動で古い VFS ノードはクリアされますが、欠けている Usenet の記事は修復されません。

この修正は、.NET のコピーフォールバックを抑止したり、破損した内容を読めるようにしたりするものではありません。SABnzbd の完了前に zurg が行う可用性チェックと、拒否された MOVE は、別の保護として残ります。可用性のサンプリングはファイル全体の検証ではありません。詳しくは `sabnzbd-client-contract.md` を参照してください。

固定されたパッチには、埋め込み union で使われるファイルエイリアスの修正も含まれています。`action_policy: all` の場合、ローカルと WebDAV の両方がファイル操作を受け取る可能性があります。ローカルの Move または Remove が成功し、WebDAV が 404 を返した場合は、失敗したアップストリームのソースが消えていることを新しいルックアップで確認できた場合にのみ成功として扱います。すべてのアップストリームが失敗した操作、ソースがまだ存在する場合、移動先の親がない場合、その他の I/O や権限のエラーは、引き続き失敗のままです。できあがったバイナリは `v1.72.0-zurg-rename-sidecar-fix` と報告するので、元の VFS のみのビルドと区別できます。
