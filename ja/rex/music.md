# rexで音楽を聴く {#music-with-rex}

rexでは、Plexamp、Plex Web、Plex for Android向けの音楽ライブラリを保存できます。音楽アドオンが各曲と、そのMusicBrainzリリース情報を送ります。名前、カバー、アーティスト情報、ジャンル、類似アーティストなどは、Plexが補完します。

できること:

- **Plexが知っているアルバム。** MusicBrainzリリース付きで送られたアルバムは、どのPlexサーバーでも同じように見え、Plexのカバーと曲名が付きます。Plexが知らないアルバムは、アドオンが送ってきた名前と画像を表示します。
- **元の品質。** 曲はFLACなど、元の形式のまま再生されます。
- **歌詞とラウドネス。** アドオンが送ってくれた場合、歌詞が曲と一緒に表示されます。また、Plexがやるようにrexもそれぞれの曲のラウドネス情報をアプリに渡します。
- **再生履歴とプレイリストは自分だけのもの。** 再生回数、評価、プレイリストはPlexアカウントごとに保存されます。Plexampのスマートプレイリストも、rex上で作成されます。

## 始める前に {#before-you-start}

| 必要なもの | 理由 |
|---|---|
| 2026.11.02 以降の日付の rex nightly | 音楽はそのビルドで入るようになりました |
| [自分のアプリ向けの rex](any-source.md) の設定 | 音楽ライブラリが表示されるのはここです |
| 音楽アドオン | rex のフィード API 経由で曲を送るプログラムなら何でもかまいません。自分のディスク上にあるアルバムのフォルダーが対象なら、[チュートリアル: 音楽アドオン](addon-music.md) が 1 つの Python ファイルで完結する例です |
| [動画の変換](any-source.md#converting-video-optional)（任意） | rex は、元の音質より低い音楽品質に設定されたアプリの場合にだけ曲を変換します |

## ステップ 1. rex をインストールして Plex アカウントに追加する {#step-1-install-rex-and-add-it-to-a-plex-account}

フォローする: [rex を自分のアプリで使う](any-source.md):

1. [手順 1. rex をインストールする](any-source.md#step-1-install-rex)。rex の LAN IP の確認も含みます。このページでは `192.168.1.20` と書いていますので、ご自身の IP に置き換えてください。
2. [手順 3. Plex アカウントに追加する](any-source.md#step-3-add-it-to-a-plex-account): 新しいアカウントに rex を登録して、ご自身のアカウントと共有します。

## ステップ2. 音楽アドオンをrexに向ける {#step-2-point-your-music-addon-at-rex}

rexには曲用のミュージックライブラリが必要です。アドオンがライブラリを宣言している場合は、アドオンが登録されるときにrexがそれを作成します。宣言していない場合は、新しいアカウントでサインインしたPlexアプリで先に追加してください: **Add Library**、**Music**、任意のフォルダー。ミュージックライブラリがまだない状態で送られた曲は拒否されます。

次に、アドオンの説明に書かれている方法で、rexのアドレス `http://192.168.1.20:32400` をアドオンに設定してください。アドオンは自分をrexに登録し、アルバムを送信します。

**確認できること。** rexのログに次のように表示されます:

```
INFO    SOURCES PUT /rex/sources/<addon> -> 200
INFO    SECTION create Music (artist) for <addon>'s music
INFO    FEED <addon> upsert: ...
```

`SECTION create` の行は、アドオンがライブラリを宣言した場合にのみ表示されます。ミュージックライブラリがrexに表示され、各アルバムはアーティストの下に並びます。rexが拒否した曲は、`no music library holds <file>` のような理由とともにログに記録されます。

## ステップ3. 音楽ライブラリを共有する {#step-3-share-the-music-library}

音楽ライブラリは新しいので、まだ誰の共有にも入っていません。新しいアカウントでサインインした状態で、**Manage Library Access**（[rexを共有する](sharing.md)）から、自分のアカウントの共有にも、他のすべてのユーザーの共有にも追加してください。

## ステップ4. 聴いてみる {#step-4-listen}

- **Plexamp**: あなたの Plex アカウントでサインインし、ライブラリとして rex の音楽ライブラリを選んでください。
- **Plex Web と Plex for Android**: 音楽ライブラリは rex のほかのライブラリと一緒にあります。

**表示されるはずの内容。** Plex のカバーとトラック名が付いたアルバム、そして写真付きのアーティストです。再生ボタンを押してください。

## できないこと {#what-it-cannot-do}

- **ラジオ、ミックス、ステーションはありません。** Plexamp のラジオ、ミックス、ステーション、「音が似た曲」には、すべての曲の解析が必要ですが、rex はそれを行いません。
- **音楽フォルダーは持っていません。** rex は何もスキャンせず、タグも読みません。Plex が名前を付けられるように、アドオンが各曲と、そのアルバムの MusicBrainz リリースを送る必要があります。
- **同じアルバムの 2 つのコピーは、2 つのアルバムとして扱われます。** どの Plex サーバーでも同じです。FLAC 版と MP3 版は、それぞれ別のアルバムとして表示されます。
- **テスト済みは Plexamp、Plex Web、Plex for Android です。** 他の Plex アプリや、Plexamp のオフラインダウンロードは試していません。

自分で音楽アドオンを書きたい場合は、[チュートリアル: 音楽アドオン](addon-music.md) から始めてください。すべてのフィールドは [rex アドオンの作り方](addons.md#music) にまとめてあります。
