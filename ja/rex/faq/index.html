rex の質問

rex のインストール前後によく聞かれることへの短い回答です。各回答から詳しいガイドにリンクしています。

インストール前に

rex とは?

Official Plex アプリ向けのメディアサーバーで、ファイルは一切持ちません。お使いのアプリには、ポスター、シーズン、視聴履歴、「続きから見る」を備えた Plex サーバーがもう 1 つ増えたように見えます。ソース は rex にライブラリの中身を伝え、各ファイルを配信します。再生を押すと rex がストリーミングするので、事前にダウンロードする必要はありません。

rex は独立したサーバーです。Plex Media Server のプラグインではなく、そのために Plex が必要なわけでもありません。両方を使いたい場合は、Plex と並べて動かしてください。名前の意味は rex をインストールする で説明しています。2 つの移行方法は Plex から rex に移行する で扱っています。

料金はかかりますか?

rex は個人利用であれば無料で、有料プランはありません。ソースコードは PolyForm Noncommercial ライセンスのもとで公開されています。商用利用は認められていません。すべてのビルドは GitHub Releases で公開されています。Android 版は Android 版 rex です。

rex の周辺のものには費用がかかる場合があります:

   
rex-stremio、ソースとして使う自作アプリやアドオン 無料
zurg nightly（debrid または Usenet ライブラリのソース） DMM スポンサー向けの特典
DMM API キー（zurg で DMM の完全一致を使うため） 任意。DMM のスポンサーになると入手可能
rex の Docker イメージ 無料で公開。Linux 向け: Docker での rex

Plex アカウントは危険になりますか?

rex は Plex が作ったものではなく、rex を登録したアカウントは Plex に停止される可能性があります。rex 専用に作った新しい無料の Plex アカウントを使い、それをご自分のアカウントに共有してください。視聴履歴、フレンド、Plex Pass はご自分のアカウントに残ります。手順は Plex アカウントに追加する にまとめています。rex の利用はご自身の責任でお願いします。

どの Plex アプリで動きますか?

Plex for Android (スマホ) Pixel 6では再生、変換、プロバイダーからのダウンロード。エミュレーターでは音楽とLive TV

4K、HDR、Dolby Vision は再生できますか?

Yes. ファイルは元の画質のまま再生されます。rex はファイルをそのままアプリに渡し、そのファイルを再生できるかどうかはアプリが判断します。アプリがファイルをそのままでは再生できない場合は、FFmpeg が設定されていれば rex が変換します (Converting video)。変換では HDR と Dolby Vision を標準の映像に変換します (Settings, Transcoder, Enable HDR tone mapping、初期設定ではオン)。可能な場合はグラフィックスチップで処理されます。Intel の OpenCL ランタイムがインストールされていれば、小型の Intel マシン (J4105) でも 4K HDR10 と Dolby Vision プロファイル 5 を 1080p に、ほぼリアルタイムで変換できます。

FFmpeg がないと、アプリで再生できないファイルには "This server is not powerful enough to convert video" と表示されます。すべてのタイトルがすべてのデバイスでこの表示になる場合、解決策は FFmpeg ではありません。Nothing plays を参照してください。

Plex for iOS と Dolby Vision。 Plex for iOS 2026.20.0 は、Dolby Vision ファイルをそのままの状態で再生すると 0:00 で止まったままになります。同じファイルを配信する実際の Plex Media Server でも同じように止まるため、原因はアプリ側にあります。HDR10 と SDR の 4K ファイルは再生できます。

Plex Pass は必要ですか?

いいえ。rex は、登録されているアカウントに Plex Pass があることを Plex アプリに伝えるので、無料アカウントでも外出先での再生や動画の変換が使えます。外出先での再生は、両側とも無料アカウントを使った Plex Web で確認しました。他のアプリでは外出先での動作はまだテストしていません。映画のエディション、Dashboard、Downloads、イントロやエンディングのスキップ、その他の Movie and TV capabilities も動作します。ただし、アプリ独自のルールが適用される場合があります。

オフラインで見るためにダウンロードできますか?

Plex アプリに Downloads があります。rex は、ダウンロード用のファイルを自分のマシン上で準備します。元のファイルのままのものと、FFmpeg で変換したものがあります。準備したファイルは rex.db の隣にあるフォルダに保存され、アプリが取りに来るまで残ります。rex に登録しているアカウントは、いつでもダウンロードできます。共有している相手は、共有設定でダウンロードが許可されている必要があります（rex の共有）。アプリ側で独自のルールが適用されることもあります。変換したダウンロードには、テキスト字幕は含まれません。スマホにダウンロードして、オフラインで見る機能はまだテストしていません。

複数の人がそれぞれの履歴で使えますか?

はい。rex を共有した相手は、それぞれ自分のアカウントでサインインし、視聴済みの状態、Continue Watching、評価、プレイリストを個別に持てます。古い Plex サーバーから視聴履歴をコピーすることもできます（視聴履歴を取り込む）。子ども向けの managed users を含め、手順は 家族や友人と rex を共有する にまとめてあります。

どんなハードウェアが必要ですか?

マシンは常時起動しているものを用意してください。Linux（amd64 または arm64、glibc 2.35 以降、つまり Ubuntu 22.04 以降）、macOS（Intel または Apple Silicon）、64 ビット版 Windows に対応しています。Android の携帯電話、タブレット、TV ボックスでは、Android 版 rex で rex とそのアドオンを無料で動かせます。スポンサー向けの zurg+rex アプリ（スマホ上で動く Plex サーバー）を使えば、デブリッドとUsenet のライブラリを rex に接続することもできます（Android ガイドを参照）。

メモリ: 1 GB 用意してください。映画 4,062 本とシリーズ 656 本のライブラリでは、起動時の rex の使用量は 500 MB 未満で、ライブラリを閲覧している間は約 730 MB でした。動画の変換にはこれに加えてメモリが必要です。

ディスク: 映画については不要です。rex はライブラリを rex.db に保存します。ダウンロードや、分析で作られる画像（シークプレビュー、チャプター画像）もその横に保存されます。使う場合のみです。

変換: FFmpeg を使う場合のみ行われます。グラフィックチップがあると速くなります。小型の Intel チップで 1080p の映画を変換すると、約 2 秒で開始します。各システムで rex がどのチップを使うかは、プラットフォーム別にまとめてあります。macOS では、常にプロセッサで変換されます。

ローカルのファイルを読み込みますか?

いいえ。rex はフォルダやディスクをスキャンすることはなく、マウントも必要ありません。すべてのファイルは HTTP 経由でソースから取得します。自分のディスク上のファイルも使えますが、それを配信する何かが必要で、そのファイルについて rex に伝える必要があります。詳しくは rex with your own app を参照してください。

Usenet にも対応していますか?

はい、Usenet を読めるソース（zurg など）を通せば可能です。rex は Usenet プロバイダーとは直接やり取りしません。ソースがファイルを読み取り、通常のファイルとして rex に配信します。zurg は Usenet の手順で設定し、zurg と組み合わせた rex の手順どおりに rex の接続先を zurg に向けてください。

zurg は必要ですか?

いいえ。zurg は複数あるソースの一つにすぎません。rex は、フィード API を話せるものなら何でも受け付けます。

  • 独自のアプリで rex: HTTP でファイルを配信するアプリなら何でも
  • Stremio のアドオンで rex: Stremio アドオンのカタログを使う
  • zurg で rex: デブリッドのアカウントまたは Usenet を使う
  • rex アドオンを作る: ホームビデオ、録画、チャンネルなど。自作のプログラムを使い、出発点として三つのチュートリアルがあります

複数のソースで、同じ Movies と TV のライブラリを埋めることができます。

ポート開放は必要ですか?

自宅外では使えません。自宅のネットワーク内にいる Plex アプリは、ルーターの設定を変えなくても rex を見つけられます。app.plex.tv も、rex 直接接続で得られる HTTPS アドレスを使えば利用できます。

外出先での視聴や別の世帯での利用には、rex に専用のアドレスが必要です。一番簡単な方法は、ポート転送を 1 つ設定することです（rex 直接接続）。IPv6 があり、グローバル IPv4 がない場合は、IPv6 経由の rex 直接接続を使ってください。Tailscale serve は、Tailscale を動かしている端末であればポート転送が不要です。各方法の比較は自宅外で使う（任意）にまとめています。

できないことは何ですか?

チューナーや DVR はありません。音楽、ライブ TV、写真には、それらを送ってくれるソースが必要です。rex での音楽再生とrex でのライブ TVを参照してください。zurg は漫画を写真として送るので、Plex Web で表示されます。Plexamp のラジオミックスとステーションは表示されません。rex にはリレー機能がないため、外出先から使うには専用のアドレスが必要です(家の外で使う)。

インストール後に

アプリに Plex のバージョンと「Check for Updates」が表示されるのはなぜですか?

rex は自分自身をアプリや plex.tv に Plex Media Server として名乗るため、アプリには Plex Media Server のバージョン番号が表示されます。その番号は rex のものではありません。Check for Updates は、サーバーが最新だと必ず答えます。rex は自分で更新しないからです。rex を更新するには、Updating の手順に従って新しい nightly をダウンロードしてください。

ブラウザで port 32400/web を開いてもライブラリが表示されないのはなぜですか?

rex には独自の Web アプリがありません。http://<rex's LAN IP>:32400/web を開くと、短いステータスページが表示されます。視聴は Plex アプリ、または app.plex.tv のブラウザで行ってください。

何が自分のマシンの外へ送信されますか?

  • plex.tv、起動時と1日に1回（登録の有無に関係なく）: サーバーのID、名前、バージョンを送り、Plexの公開リリース一覧で最新のバージョン番号を確認します。
  • plex.tv、Plexアカウントに登録後: claim、サーバーのアドレス（LANアドレスとHTTPSアドレス）、ライブラリ名。
  • Plexのメタデータサービス、登録後: 各タイトルのID。名前、ポスター、あらすじ、エピソードを取得するためです。Search Subtitles による字幕検索や、人ごとの自動字幕設定では、ファイル名とフィンガープリントを送ります。
  • アートワークのホスト、アプリが表示するとき: ソースが指定するポスターや画像へのリクエスト。
  • DMM、rex-direct用、登録後は6時間ごと: サーバーのID、Plexアカウント上のトークン、LAN IP。DMMはplex.tvに問い合わせて、そのサーバーがあなたのものか確認し、公開IPを確認して、rex-directの名前をそのサーバーとLAN IPに向けます。マシンにグローバルIPv6アドレスがあれば、rexはそれも送ります。起動後（またはclaim後）1分後に送り、その後は6時間ごとに送ります。DMMが接続して同じサーバーに届くか確認するたびにも送ります。REX_DIRECT_URL=off で無効にできます。
  • ソース（再生時と削除時）: 再生するファイルへのリクエストと、削除（下記）。
  • 古いPlexサーバー（視聴履歴を持ち込む場合のみ）: 視聴履歴へのリクエスト。
  • Webhook（設定した場合のみ）: 設定したアドレスへのイベント。

rexは、リリースが何かを誰にも尋ねません。決めて伝えるのはソースです。たとえばzurgはDMMに尋ねます（DMMがファイルを配置する理由）。

Plex アプリで削除するとファイルも消えますか?

はい。rex が登録されているアカウントでサインインした Plex アプリで映画やエピソードを削除すると、Plex サーバーがディスクからファイルを消すのと同じように、ソース側のファイルも削除されます。debrid アカウントのソース（zurg など）の場合は、そちらでファイルが削除されます。ソースが削除を拒否した場合は、タイトルはそのまま残り、アプリに削除できなかったと表示されます。共有している相手は削除できません。オフにする方法は Plex アプリでの削除 で説明しています。

何も再生されない、またはすべてのアプリで「not powerful enough」と表示される

Play を押した直後の rex のログを見てください。そこに upstream failed や 502 が出ている場合、rex はソースがそのアドレスで接続できていません。FFmpeg をインストールしても、これは解決しません。

よくある原因は、Windows や macOS の Docker Desktop で動かしている zurg です。zurg と組み合わせた rex または 独自のアプリと組み合わせた rex の upstream failed の行で、アドレスを確認し、何を変更すればよいかを説明しています。

一部のファイルだけが失敗する場合（多くは Web ブラウザでだけ起きます）は、デバイスがそのままの形式では再生できないことが原因です。動画の変換 を設定してください。

タイトルが間違って一致しました。どう直しますか?

ソースが各ファイルの正体を決め、rexはそのタイトルを表示します。rexに登録されているアカウントでサインインし、Fix Matchを使ってください。rexは選んだ内容を保持し、zurgがそうしているように、ソースがそれを読み戻して、そのリリースの一致情報として残すこともできます(DMMがファイルを配置する理由)。

ヘルプはどこで得られますか?

Getting help では、どこで質問すればよいか、何を含めるべきかを説明しています。質問先は Discord の rex-support フォーラムで、スポンサー向けのリモートサポートもあります。
