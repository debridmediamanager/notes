TorBox での DMM

Debrid Media ManagerでTorBoxを使う方法です。APIキーでのサインイン、無料プランでできないこと、Instant TBの結果、ライブラリ、Cast、TorBox ProへのUsenetリリースの送信、そして表示される可能性のあるエラーについて説明します。

DMMはTorBoxの有料プラン（Essential、Standard、Pro）で動作します。torbox.app/settingsからAPIキーをコピーして、DMMのConnect Torboxページに貼り付けてください。その後検索すると、TorBoxにすでにあるリリースにはInstant TBが表示されます。無料プランはAPIアクセスがないため、DMMでは使えません。また、UsenetのリリースをTorBoxに送るにはProプランが必要です。

サインイン

  1. debridmediamanager.com で Login with Torbox を押します。すでに別のサービスでサインインしている場合は、ホームページの Debrid services を開き、Torbox Login を押します。
  2. Get API Key from Torbox を押します。torbox.app/settings が開き、そこにAPIキーがあります。
  3. キーを API Key に貼り付け、Save API Key を押します。

サインインできたら、ホームページに Cast for TB と Requests が表示されます。Debrid services には、TorBoxアカウントが ✓ 付きで一覧されます。それを押すと、プランと期限を確認できます。また、Add another account や Logout もここから操作できます。

各プランでできること

  Free Essential or Standard Pro
DMMにサインイン No Yes Yes
Instant TB、DL with TB、ライブラリ、Cast (TB) No Yes Yes
Usenetのリリースをtorboxに送信 No No Yes
同時ダウンロード数（TorBoxのアクティブスロット） 1 3 or 5 10

無料プランのキーでサインインすると、DMMは Your TorBox account is on the free plan, which has no API access. DMM needs a paid TorBox plan. と表示します。TorBoxの料金ページでは、APIアクセスは無料プランには含まれず、UsenetはProプランのみと記載されています。

TorBox にすでにあるものを探す

  1. 映画かシリーズを検索して開きます。
  2. DMM が TorBox に、どのリリースがキャッシュ済みかを問い合わせます。キャッシュ済みのものには Instant TB と Cast (TB) が表示され、一覧の先頭に並びます。結果の上にある TB ✓ チップを押すと、これらだけに絞り込まれます。そのとき入力欄には is:tb と書かれます。もう一度押すと、すべて表示に戻ります。
  3. Instant TB を押します。そのリリースはすぐに TorBox のライブラリに入ります。

TorBox にないリリースには DL with TB が表示されます。これを押すと、まず TorBox がそのリリースをダウンロードします。ダウンロード中は、アクティブなスロットを 1 つ使います。サイズの横に No seeders と出ている場合は、今は誰も共有していないということなので、完了しない可能性があります。TorBox ではリリース全体がまとめて追加されます。個別のファイルだけを選ぶことはできません。

あなたのライブラリ

Library を押します。TorBox のトレントとウェブダウンロードの一覧が表示されます。

  • TB Add を押すと Add to your TB library が開きます。マグネットリンクを貼り付けたり、.torrent ファイルをアップロードしたりできます。直接ダウンロードリンクを貼り付けると、TorBox がウェブダウンロードとして取得します。
  • Backup で一覧をファイルに保存できます。TB Restore を使うと、保存した一覧を元に戻せます。
  • それ以外の操作は、ほかのサービスと同じです。your library を参照してください。

TorBox に送った Usenet のダウンロードは、DMM のライブラリには表示されません。TorBox のサイトで確認するか、Stremio の DMM Cast にある DMM TB Library の行で探すか、zurg の TorBox でホストされている Usenet から確認してください。

Stremio で視聴する

ホームページでCast for TBを押して、そこからアドオンをインストールしてください。その後、TorBoxでキャッシュ済みの任意のリリースで**Cast (TB)**を押します。手順はすべてStremio で DMM を使うにあります。

Stremioではアドオン名はDMM Cast for TorBoxです。DMM TB Libraryの行には、TorBoxのトレントと、完了したWebおよびUsenetのダウンロードが表示されます。

Usenet のリリースを TorBox に送る (Pro)

  1. 映画や番組を開いて、Usenet タブを押します。
  2. TorBox Pro の場合、リストの見出しは Send to TorBox になり、各リリースに TorBox ボタンがあります。それを押します。
  3. DMM が TorBox の処理結果を表示します:
    • Usenet → TorBox: TorBox already had it, it is ready in your TorBox Usenet downloads.
    • Usenet → TorBox: TorBox is downloading it, usually ready within a few minutes.
    • Usenet → TorBox: queued, it starts when one of your TorBox active slots frees up.

Real-Debrid にもサインインしていますか？その場合、リストの見出しは Send to Real-Debrid or TorBox になり、両方のボタンが表示されます。行の末尾にあるファイルアイコンを押すと、代わりに NZB を保存できます。Usenet が初めてなら、まず Usenet入門 を読んでください。

TorBox は、Usenet のダウンロードをキャッシュしてから 30 日後に削除します。元に戻すには、もう一度送信してください。

TorBox でリクエストを満たす

Real-Debrid のユーザーは、DMM のリクエストボードでリリースを頼めます。ホームページで Requests を押し、TorBox にキャッシュ済みのリリースで Fulfil を押してください。TorBox 側のリリースが Real-Debrid のアカウントに送られます。10 回送るごとに DMM のスポンサー特典が 7 日分もらえます。お金を払わずに獲得する方法を参照してください。

よくある質問

zurg の無料プランでは TorBox に対応していないのですか?

zurgの無料の公開ビルドはReal-Debridのみ対応しています。TorBox、その他のサービス、Usenetは、スポンサー向けのzurgのnightlyビルドに含まれています。zurgは無料アカウントを読み取れないため、TorBoxのプランも有料である必要があります。設定はzurgでのTorBoxの設定を参照してください。

zurg が間違った TorBox プランを使っている?

zurgのnightly版で2026年10月3日より前のものは、TorBoxのPro planをStandardとして扱い、同時ダウンロード数を10ではなく5にしてしまいます。zurgを更新してください。残りの内容はzurgでのTorBoxの制限にあります。

TB で検索結果が出てこない?

DMMの検索は、どのサービスでサインインしていても同じです。TorBoxは、どのリリースにInstant TBと表示するかを決めるだけです。何も表示されない場合は、TB ✓チップがオフになっているか確認し、ページを再読み込みするか、一番下のShow More Resultsを押してください。放送されたばかりの新しいエピソードは、まだDMMにトレントがない場合があります。その場合はUsenetタブを試してください。

TorBox と Real-Debrid は一緒に使えますか?

はい。両方のサービスにサインインすると、各リリースに両方のサービスのボタンが表示されます。TorBox にはキャッシュされているのに Real-Debrid にはないリリースには TB → RD ボタンが付き、クリックするとそのリリースを TorBox から自分の Real-Debrid に送れます。

DMM にはどの TorBox プランが必要ですか?

どの有料プランでも構いません。Usenetのリリースを TorBox に送りたい場合や、同時に10件のダウンロードをしたい場合は Pro を選んでください。
