# rex

[rex](https://rex.debridmediamanager.com/fr/) est un serveur multimédia pour les applications Plex officielles qui ne possède aucun fichier. Une source lui indique ce qui se trouve dans votre bibliothèque et fournit chaque fichier. rex diffuse ce fichier quand vous appuyez sur lecture. rex est gratuit pour un usage personnel. Son [code source](https://github.com/debridmediamanager/rex) est public sous la licence PolyForm Noncommercial. Il fonctionne sur Linux, macOS et Windows, ainsi que sous forme d'image Docker Linux `ghcr.io/debridmediamanager/rex:nightly` ([avec votre propre application](any-source.md#run-rex-in-docker), [avec zurg](with-zurg.md#run-rex-in-docker)).
