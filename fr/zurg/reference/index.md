# Référence {#reference}

Pages de référence. Rien ici n'est un tutoriel. Consultez-les quand vous savez ce que vous voulez et avez besoin du nom exact.

| Page | Consultez-la quand |
|---|---|
| [Configuration](config.md) | Vous voulez le nom exact et la valeur par défaut d'une clé de `config.yml`. Toutes les options que zurg accepte sont sur cette page. |
| [Ligne de commande](cli.md) | Vous voulez une commande ou un drapeau que le binaire accepte. |
| [Tags](tags.md) | Vous filtrez un répertoire sur les tags `zurg_*` et vous voulez savoir lesquels sont appliqués et pourquoi. |
| [Identité sortante](outbound-identity.md) | Vous voulez savoir ce que zurg indique aux services qu'il appelle à son sujet. |
| [Serveur MCP](mcp.md) | Vous voulez qu'un agent IA pilote zurg, et vous avez besoin des jeux d'outils qu'il expose et de ce que chacun peut faire. |
| [Journal des modifications](changelog.md) | Vous voulez savoir ce qui a été livré et quand. |

Le comportement des fournisseurs a été déplacé ici. Les limites de TorBox et les serveurs de news inclus se trouvent dans [Fournisseurs](../providers/index.md). C'est aussi là qu'on configure un compte pour la première fois. Pour réaliser une tâche précise avec la bibliothèque, consultez [Guides](../guides/index.md).
