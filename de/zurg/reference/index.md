# Referenz {#reference}

| Seite | Lies sie, wenn |
|---|---|
| [Konfiguration](config.md) | Du willst den genauen Namen und Standardwert eines `config.yml`-Schlüssels wissen. Jede Option, die zurg akzeptiert, steht auf dieser einen Seite. |
| [Kommandozeile](cli.md) | Du suchst einen Befehl oder ein Flag, das das Programm annimmt. |
| [Tags](tags.md) | Du filterst ein Verzeichnis nach `zurg_*`-Tags und musst wissen, welche gesetzt werden und warum. |
| [Ausgehende Identität](outbound-identity.md) | Du willst wissen, was zurg den Diensten, die es aufruft, über sich selbst mitteilt. |
| [MCP-Server](mcp.md) | Du willst einen KI-Agenten zurg steuern lassen und brauchst die Toolsets, die zurg bereitstellt, und was jedes davon darf. |
| [Änderungsprotokoll](changelog.md) | Du willst wissen, was wann veröffentlicht wurde. |
