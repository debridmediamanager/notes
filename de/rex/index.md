# rex

[rex](https://rex.debridmediamanager.com/de/) ist ein Medienserver für die offiziellen Plex-Apps, der selbst keine Dateien besitzt. Eine Quelle teilt rex mit, was in deiner Bibliothek liegt, und liefert jede Datei aus. rex streamt die Datei, wenn du auf Wiedergabe drückst. rex ist für die private Nutzung kostenlos. Der [Quellcode](https://github.com/debridmediamanager/rex) ist unter der PolyForm-Noncommercial-Lizenz öffentlich. rex läuft unter Linux, macOS und Windows sowie als Linux-Docker-Image `ghcr.io/debridmediamanager/rex:nightly` ([mit deiner eigenen App](any-source.md#run-rex-in-docker), [mit zurg](with-zurg.md#run-rex-in-docker)).
