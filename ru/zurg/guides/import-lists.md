# Следим за списком в Sonarr и Radarr {#following-a-list-in-sonarr-and-radarr}

Sonarr и Radarr могут следить за списком сериалов или фильмов. Каждое название из списка добавляется и ищется. Если zurg выступает клиентом загрузки, каждая раздача попадает на ваш аккаунт debrid и импортируется в `__magic__`, как и любая другая. Поэтому список — это целый раздел библиотеки, который заполняется сам. Список ужасов даёт вам раздел ужасов, а новые названия появляются по мере того, как список растёт.

Эта страница предполагает, что \*arrs уже получают файлы через zurg. Если пока нет, начните с [Sonarr и Radarr для торрентов](sonarr-radarr-torrents.md).

## Используйте MDBList, а не IMDb {#use-mdblist-and-not-imdb}

Обе программы всё ещё показывают тип списка IMDb, но ни одна из них больше не работает с обычным списком IMDb.

- Radarr не принимает ID списка вида `ls12345678`. Он принимает только `top250`, `popular` или список пользователя `ur12345678`.
- Sonarr принимает ID, а затем получает от IMDb пустой ответ. Кнопка Test пишет `Imdb call resulted in an unexpected StatusCode [Accepted]`.

[MDBList](https://mdblist.com) помогает обойти обе проблемы. Он публикует любой список как JSON-ленту, которую обе программы читают через свой тип Custom List. Фильмы и сериалы лежат в разных списках, поэтому добавлять их нужно в каждую программу отдельно.

## 1. Выберите список {#1-pick-a-list}

Публичные списки не требуют аккаунта. Найдите в MDBList нужный жанр и откройте подходящий список. Два хоррор-списка, которые работают на октябрь 2026 года:

| Список | Содержит | URL ленты |
|---|---|---|
| Horror | фильмы | `https://mdblist.com/lists/garycrawfordgc/horror/json` |
| Horror Shows | сериалы | `https://mdblist.com/lists/garycrawfordgc/horror-shows/json` |

URL ленты — это адрес страницы списка с `/json` в конце. Сначала откройте его в браузере. Вы должны увидеть страницу с текстом, который начинается с `[{"id":`.

Чтобы создать свой список, войдите в MDBList и создайте его. Он может следовать фильтрам, например жанру и минимальному рейтингу, или копировать уже имеющийся у вас список IMDb. URL ленты работает так же.

## 2. Добавьте его в Radarr {#2-add-it-to-radarr}

**Settings → Import Lists → + → Custom Lists**

| Field | Value |
|---|---|
| Name | любое, например `Horror` |
| Enable | включено |
| Enable Automatic Add | включено |
| Search on Add | сначала прочитай предупреждение ниже |
| Monitor | Movie Only |
| Root Folder | твоя папка с фильмами внутри `__magic__`, например `/mnt/zurg/__magic__/movies` (`/Volumes/Zurg/__magic__/movies` на macOS, `Z:\__magic__\movies` на Windows) |
| Quality Profile | тот, который ты используешь |
| List URL | URL ленты с фильмами |

Нажми **Test**, а затем **Save**.

## 3. Добавьте его в Sonarr {#3-add-it-to-sonarr}

**Settings → Import Lists → + → Custom List**

| Поле | Значение |
|---|---|
| Name | что угодно, например `Horror Shows` |
| Enable Automatic Add | вкл. |
| Monitor | All Episodes, или Pilot Episode, если сначала хотите попробовать сериал |
| Root Folder | ваша папка с сериалами внутри `__magic__`, например `/mnt/zurg/__magic__/tv` (`/Volumes/Zurg/__magic__/tv` на macOS, `Z:\__magic__\tv` на Windows) |
| Quality Profile | тот, которым вы пользуетесь |
| Series Type | Standard |
| Season Folder | вкл. |
| Search for Missing Episodes | сначала прочитайте предупреждение ниже |
| List URL | URL ленты сериала |

Нажмите **Test**, а затем **Save**.

## Большие списки забирают всё сразу {#big-lists-grab-everything-at-once}

Список с включённым поиском при добавлении захватывает каждый тайтл в момент синхронизации. В списке фильмов 400 тайтлов, в списке сериалов 148 шоу со всеми эпизодами. Это очень много захватов сразу. Ваш аккаунт debrid и индексаторы почувствуют нагрузку, а индексатор с лимитом запросов начнёт отказывать в поиске.

Есть два более мягких способа.

- Оставьте поиск при добавлении выключенным. Тайтлы будут добавлены и отслеживаться, но поиск не запустится. Ищите нужные вам на страницах Movies или Series.
- Начните с короткого списка. Большой список добавьте, когда первая партия уже приземлилась.

Приложения также синхронизируют списки по своему расписанию. **System → Tasks → Import List Sync** запускает синхронизацию прямо сейчас.

## Удаление списка {#removing-a-list}

Удаление списка останавливает поступление новых тайтлов из него. То, что он уже добавил, остаётся. В **Settings → Import Lists** параметр **Clean Library Level** определяет, что происходит с тайтлами, которые выпадают из списка. Оставьте его в Disabled, если только вы не хотите, чтобы приложения сами что-то удаляли.
