# zurg+rex для Android и Google TV {#zurgrex-for-android-and-google-tv}

Приложение для Android запускает на устройстве движок zurg, а рядом с ним rex: это ваш собственный сервер Plex на телефоне или ТВ-приставке, для приложений Plex. Одно приложение работает на телефонах, планшетах, Android TV и Google TV. Требуется Android 8.0 или новее. Fire TV может установить тот же APK в обход магазина. Используйте плеер с поддержкой WebDAV, если на устройстве нет системного приложения Files. Usenet требует 64-битный Android; NZB-файлы, размещённые на TorBox (`torbox_nzb`), на Android недоступны.

## Установка и настройка {#install-and-set-up}

[Скачайте APK](https://zurg.debridmediamanager.com/ru/download.html#android) из ночного релиза приватного репозитория спонсора. Для большинства телефонов и ТВ-боксов выбирайте `arm64-v8a`, для старых 32-битных устройств `armeabi-v7a`, а для эмулятора или совместимого Chromebook `x86_64`. Каждый APK включает интерфейсы для телефона и ТВ.

Сам zurg в приложение не входит. После входа в GitHub установите движок прямо из приложения. Нужен аккаунт спонсора. Станьте спонсором на [gatekeeper](https://gatekeeper.debridmediamanager.com/), чтобы ваш аккаунт GitHub получил доступ. Setup проведёт вас через все шаги.

Разрешите установку из приложения, которым вы открываете APK. Android или Play Protect могут попросить подтвердить установку из сторонних источников. ID приложения: `com.debridmediamanager.zurg`. Обновления должны сохранять подпись релиза.

1. Откройте zurg, войдите в GitHub и установите версию движка. Пока движок не установлен, приложение не может запустить библиотеку.
2. Добавьте аккаунты провайдеров и проверьте учётные данные. Имена аккаунтов нужны, чтобы различать несколько аккаунтов одного провайдера. Лимиты подключений Usenet учитывают всех остальных, кто использует этот аккаунт.
3. Выберите Phone, Tablet, TV box или TV stick. Профили задают целевой объём памяти движка и размеры дискового кэша. Целевой размер Go heap не является жёстким ограничением RSS.
4. Разрешите уведомления и фоновую работу. Включите start after reboot, если это устройство должно всегда раздавать библиотеку.
5. Запустите библиотеку. Первая загрузка большого аккаунта может занять несколько минут. О готовности папок сообщат уведомление и экран Status.

## Смотреть на этом устройстве {#watch-on-this-device}

Используйте **Library**, чтобы просматривать папки и воспроизводить файл. **More** предлагает другой плеер или Android document URI. Выбранный плеер можно сделать предпочтительным. Файлы и средства выбора документов показывают одну и ту же библиотеку в корне хранилища zurg. Файлы воспроизводятся с произвольным доступом, их не нужно сначала полностью скачивать. Один раз откройте свой плеер и завершите его настройку, прежде чем выбирать его в **Files**.

Для плееров с WebDAV добавьте `http://127.0.0.1:9999/dav/` как источник. Если вы меняли порт, используйте тот, который показан в **Status**. VLC, Kodi и Nova умеют просматривать источник WebDAV. Плееры, которые принимают только отдельные URL, можно запускать из **Library**. На ТВ используйте D-pad и Select, чтобы перемещаться по элементам управления и нажимать их, Back, чтобы вернуться, а Menu или More для действий с релизом. Чтобы редактировать текстовое поле, выберите его, а затем нажмите Back, чтобы вернуться к навигации. На телефоне для открытия **More** также можно сделать долгое нажатие.

Repair, rename, tags, show all files и delete действуют на весь релиз, которому принадлежит файл. Удаление запрашивает подтверждение и удаляет файлы из аккаунта провайдера. **MediaInfo** использует встроенный ffprobe и выводит подробные сведения о видео-, аудио- и субтитрах на панели. Никакой отдельной установки медиа-инструмента не требуется.

## Смотреть в приложениях Plex {#watch-in-the-plex-apps}

Начиная с ночной сборки от 10 ноября 2026 года, приложение также запускает rex (на 64-битных устройствах в этой ночной сборке, а на всех поддерживаемых устройствах начиная с ночной сборки от 11 ноября), медиасервер для приложений Plex, и направляет на него zurg. Благодаря этому твоя библиотека появляется в официальных приложениях Plex и в Plezy — на этом устройстве и на других устройствах в твоём доме. Когда библиотека запущена, в Status появляется **rex for the Plex apps**: выбери **Sign in to Plex** и подтверди вход (на телевизоре введи код на plex.tv/link). Сервер появляется в Plex под именем этого устройства. rex перекодирует то, что плеер не может воспроизвести, с помощью аппаратного кодировщика устройства. Чтобы выключить rex, открой Settings, Connection; после этого zurg перестанет передавать ему файлы.

## Поделиться по локальной сети {#share-over-the-local-network}

В Settings включите **Expose on local network**. zurg сгенерирует учётные данные и покажет LAN-адрес WebDAV устройства. Введите этот адрес и учётные данные в плеере на другом устройстве. Android-хост должен оставаться включённым и работающим. HTTP basic authentication не шифрует трафик, поэтому используйте только доверенную локальную сеть. По умолчанию используется loopback. Intent-ы плеера никогда не содержат пароль вашего сервера.

## Настройки, резервные копии и обновления {#settings-backups-and-updates}

Settings покрывает подключение, провайдеров, библиотеку, восстановление, ресурсы и логирование.
Advanced принимает сырой YAML и просит установленный движок проверить его перед
сохранением. В Settings нет поля для твоего API-ключа DMM: добавь
`dmm_api_key: YOUR_DMM_API_KEY` в Advanced для [списка желаемого DMM](dmm-wanted.md)
и именования релизов DMM. При сохранении работающей конфигурации приложение спрашивает, можно ли перезапустить сервер.
Web dashboard открывает локальную панель для настроек интеграции с десктопом.

Logs содержит последний вывод движка и последние 200 строк от supervisor.
Общие логи скрывают настроенные секреты и URL. Бэкапы содержат учётные данные и
состояние библиотеки, поэтому храни их в надёжном месте. Перед восстановлением останови zurg.
Android не принимает ссылки на бэкапы и специальные файлы, а восстанавливает сначала на loopback.

Updates проверяет приватный репозиторий спонсора. Вход в GitHub через устройство запрашивает
область `repo`, потому что файлы релизов приватные. Токены GitHub шифруются
в настройках на базе Android Keystore. Также поддерживается токен, который ты задаёшь вручную, с правом
чтения репозитория. Если Android больше не может расшифровать сохранённый вход, Updates
просит тебя войти снова, а конфигурация библиотеки сохраняется. Скачанные обновления должны совпадать
по application ID и ключу подписи и иметь более высокий version code. Установщик Android
спрашивает разрешение перед заменой приложения.

Если обновиться со сборки, которая включала собственный движок, в приложении движка не останется.
Установи движок из Updates один раз, и твои провайдеры и настройки библиотеки перенесутся без изменений.

Приложение и движок обновляются отдельно. Updates показывает версии движка из
30 последних релизов репозитория спонсора, отмечает ту, что у тебя стоит, и устанавливает любую
из них. Если новый nightly работает на твоём устройстве плохо, установи ту версию, которая работала. Перед сменой движка останови библиотеку на Status. Приложение
запускает только пакет движка, подписанный его собственным ключом, и проверяет подпись при каждом запуске.

У постоянного уведомления есть действие Stop. Плитка Quick Settings тоже
запускает и останавливает сервер. Battery exemption помогает с ограничениями простоя Android. Фирменные убийцы фоновых задач могут требовать дополнительных настроек из [Не убивай моё приложение](https://dontkillmyapp.com/).
