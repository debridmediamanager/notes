# zurg Tags Documentation

Этот документ описывает все возможные теги, которые могут автоматически применяться к торрентам в zurg.

## Теги разрешения {#resolution-tags}

Теги разрешения применяются по размерам видео с допуском 5%: поток подходит под уровень, если и ширина, и высота составляют не меньше 95% от указанных размеров. Встроенные изображения (обложки, миниатюры) игнорируются. Применяется только самый высокий подходящий тег разрешения.

| Тег | Описание |
|-----|-------------|
| `zurg_8k` | Разрешение >= 7680x4320 |
| `zurg_4k` | Разрешение >= 3840x2160 |
| `zurg_1440p` | Разрешение >= 2560x1440 |
| `zurg_1080p` | Разрешение >= 1920x1080 |
| `zurg_720p` | Разрешение >= 1280x720 |
| `zurg_480p` | Разрешение >= 720x480 |

## Теги динамического диапазона {#dynamic-range-tags}

Применяется только один из этих тегов, в зависимости от характеристик динамического диапазона видео:

| Тег | Описание |
|-----|----------|
| `zurg_hdr` | HDR-контент (определяется по цветовому пространству BT.2020) |
| `zurg_dv` | Контент Dolby Vision |
| `zurg_sdr` | Контент со стандартным динамическим диапазоном (SDR), применяется, когда не обнаружены ни HDR, ни DV |

Если присутствуют и метаданные HDR, и метаданные Dolby Vision, приоритет у тега Dolby Vision, а `zurg_hdr` не применяется.

## Теги битрейта видео {#video-bitrate-tags}

Теги битрейта видео основаны на самом высоком битрейте видеопотока, найденном во всех проанализированных файлах. Встроенные изображения (обложки, миниатюры) не учитываются. Применяется только самый высокий подходящий уровень.

| Тег | Описание |
|-----|----------|
| `zurg_ultra_high_video_bitrate` | Битрейт видео ≥ 100 Mbps |
| `zurg_high_video_bitrate` | Битрейт видео ≥ 70 Mbps и < 100 Mbps |
| `zurg_moderate_video_bitrate` | Битрейт видео ≥ 40 Mbps и < 70 Mbps |
| `zurg_low_video_bitrate` | Битрейт видео ≥ 10 Mbps и < 40 Mbps |
| `zurg_very_low_video_bitrate` | Битрейт видео ≥ 0 Mbps и < 10 Mbps |

## Теги битрейта аудио {#audio-bitrate-tags}

Теги битрейта аудио основаны на самом высоком битрейте аудио, найденном во всех аудиодорожках. Применяется только самый высокий подходящий уровень.

| Тег | Описание |
|-----|-------------|
| `zurg_ultra_high_audio_bitrate` | Битрейт аудио ≥ 2000 kbps (например, DTS-HD MA, TrueHD, LPCM) |
| `zurg_high_audio_bitrate` | Битрейт аудио ≥ 768 kbps и < 2000 kbps (например, DTS, AC3 с высоким битрейтом) |
| `zurg_moderate_audio_bitrate` | Битрейт аудио ≥ 384 kbps и < 768 kbps (например, обычный AC3, AAC 5.1) |
| `zurg_low_audio_bitrate` | Битрейт аудио ≥ 128 kbps и < 384 kbps (например, стерео AAC, MP3) |
| `zurg_very_low_audio_bitrate` | Битрейт аудио ≥ 0 kbps и < 128 kbps (например, низкокачественное стерео) |

## Теги длительности {#duration-tags}

Теги длительности основываются на самой большой длительности, найденной во всех проанализированных файлах, включая файлы только с аудио. Применяется только самый высокий подходящий уровень.

| Tag | Description |
|-----|-------------|
| `zurg_80minsplus_duration` | Длительность ≥ 80 минут |
| `zurg_60to80mins_duration` | Длительность ≥ 60 минут и < 80 минут |
| `zurg_40to60mins_duration` | Длительность ≥ 40 минут и < 60 минут |
| `zurg_20to40mins_duration` | Длительность ≥ 20 минут и < 40 минут |
| `zurg_0to20mins_duration` | Длительность ≥ 0 минут и < 20 минут |

## Теги языка {#language-tags}

Теги языков применяются для каждого уникального языка, найденного в аудио- и субтитровых дорожках. Детекция объединяет все проанализированные файлы торрента, так что в сезонном паке будут языки всех его эпизодов. Учитываются только дорожки внутри проанализированных видео- и аудиофайлов: отдельный `.srt` рядом с ними никогда не читается, а дорожки без объявленного языка получают `und`.

### Теги языка аудио {#audio-language-tags}
Формат: `zurg_aud_[language_code]`

Пример:
- `zurg_aud_eng` - аудиодорожка на английском
- `zurg_aud_jpn` - аудиодорожка на японском

### Теги языка субтитров {#subtitle-language-tags}
Формат: `zurg_sub_[language_code]`

Пример:
- `zurg_sub_eng` - английские субтитры
- `zurg_sub_spa` - испанские субтитры

## Использование тегов для фильтрации {#using-tags-for-filtering}

Теги можно использовать в конфигурационном файле, чтобы раскладывать торренты по определённым папкам. Есть четыре фильтра на основе списков и ещё два условия для одного тега:

### Типы фильтров по тегам {#tag-filter-types}

1. `tags_match_all`: Все указанные теги должны присутствовать
   ```yaml
   tags_match_all: ["zurg_4k", "zurg_hdr"]  # Must have both 4K and HDR
   ```

2. `tags_match_any`: Должен присутствовать хотя бы один из указанных тегов
   ```yaml
   tags_match_any: ["zurg_aud_eng", "zurg_sub_eng"]  # Must have either English audio or subtitles
   ```

3. `tags_missing_all`: Возвращает true, если ни один из тегов фильтра не присутствует (противоположность "tags_match_any")
    ```yaml
    tags_missing_all: ["zurg_aud_eng", "zurg_sub_eng"]  # Must not have English audio or subtitles
    ```

4. `tags_missing_any`: Возвращает true, если отсутствует хотя бы один из тегов фильтра (противоположность "tags_match_all")
    ```yaml
    tags_missing_any: ["zurg_4k", "zurg_hdr"]  # Must be missing either 4K or HDR (or both)
    ```

Названия тегов в этих четырёх фильтрах сравниваются без учёта регистра. Торрент без единого тега не пройдёт `tags_match_all` и `tags_match_any`, но пройдёт `tags_missing_all` и `tags_missing_any`. Именно туда попадают торренты, которые ещё ни разу не анализировались.

Эти четыре ключа проверяются в порядке, указанном выше, и первый найденный ключ решает судьбу всего блока фильтров, поэтому дайте каждому фильтру тегов собственную запись под `and:`/`or:`, а не объединяйте несколько в одном блоке.

### Условия для одного тега {#single-tag-conditions}

`has_tag` и `not_has_tag` принимают одно имя тега, а не список, и сравнивают его с учётом регистра. В отличие от четырёх фильтров выше, они могут только отсеять торрент, но не выбрать его сами по себе. Блок фильтров, в котором есть только `has_tag`, не подходит ни под один торрент, поэтому их нужно ставить вместе с другим условием в том же блоке.

```yaml
- has_tag: zurg_4k       # gate: torrent must carry this tag
  regex: /.*/            # and a condition that can match on its own
```

### Пример конфигурации директории {#example-directory-configuration}

Вот пример того, как использовать фильтры по тегам в конфигурации каталога:

```yaml
"quality movies":
  filters:
    - and:
      - tags_match_all: ["zurg_4k", "zurg_hdr"]  # Must have both 4K and HDR
      - tags_match_any: ["zurg_high_video_bitrate", "zurg_ultra_high_video_bitrate"]  # Must have either high or ultra-high video bitrate
      - tags_match_any: ["zurg_high_audio_bitrate", "zurg_ultra_high_audio_bitrate"]  # Must have either high or ultra-high audio bitrate
      - tags_match_any: ["zurg_60to80mins_duration", "zurg_80minsplus_duration"]  # Must be at least 60 minutes long
      - tags_missing_all: ["zurg_sdr", "zurg_very_low_video_bitrate"]  # Must not have SDR or very low video bitrate
      - tags_missing_any: ["zurg_dv"]  # Must be missing Dolby Vision (prefer HDR10)
```

## Заметки {#notes}

Теги применяются автоматически на основе анализа медиа. Для этого нужен бинарный файл `ffprobe`, и анализ запускается для только что добавленных торрентов, только если включена настройка `auto_analyze_new_torrents`. Действие analyze на дашборде и действие «media info» для торрента на странице manage запускают анализ вручную.
- Ничего не помечается тегами, пока не проанализирован хотя бы один файл. Торрент без анализа не получает `zurg_sdr`, уровня битрейта и уровня длительности.
- Каждый тег `zurg_*` очищается и пересчитывается при каждом запуске анализа. Теги без этого префикса (пользовательские теги, назначения директорий) сохраняются.
- Можно одновременно иметь несколько языковых тегов.
- Применяется только один тег разрешения (самый высокий подходящий).
- Применяется только один тег динамического диапазона.
- Применяется только один тег уровня битрейта видео (самый высокий подходящий).
- Применяется только один тег уровня битрейта аудио (самый высокий подходящий).
- Применяется только один тег уровня длительности (самый высокий подходящий).
- Для проверок разрешения используется допуск 5%.
- Битрейт видео считается по потоку с самым высоким битрейтом (а не по среднему).
- Битрейт аудио считается по потоку с самым высоким битрейтом (а не по среднему).
- Поток, который не сообщает битрейт, считается как 0, поэтому файл, в метаданных потоков которого нет битрейта, попадает в уровень `very_low`.
- Длительность определяется по самому длинному проанализированному файлу в торренте (включая файлы только с аудио).
- Фильтры по тегам можно комбинировать с другими фильтрами для точной организации контента.
