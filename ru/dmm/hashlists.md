# DMM хэш-списки: добавь чужую библиотеку в свою {#dmm-hash-lists-add-someones-library-to-yours}

Хеш-список — это список релизов, которыми кто-то поделился из своей библиотеки debrid через DMM. Откройте его, войдите в DMM со своим debrid-сервисом и нажмите кнопку вашего сервиса: релизы попадут в ваш собственный аккаунт. Общие списки доступны на [hashlists.debridmediamanager.com](https://hashlists.debridmediamanager.com), а свой список можно опубликовать в разделе **Library** кнопкой **Share List**.

Список содержит названия релизов, их хеши и размеры. Файлов и аккаунтов в нём нет.

## Найти список {#find-a-list}

- На главной странице DMM нажмите **Hash lists**. Откроется [hashlists.debridmediamanager.com](https://hashlists.debridmediamanager.com) со случайным списком. **Previous hash list**, **Random hash list** и **Next hash list** переключают между списками.
- Люди публикуют списки на форуме **hashlists** в [Discord](https://discord.com/invite/7u4YjMThXP). Каждый список — это ссылка вида `https://hashlists.debridmediamanager.com/<id>.html`. Если открыть её, список откроется в DMM.

## Добавить список в свою библиотеку {#add-a-list-to-your-library}

1. Откройте список. Если на нём написано **Login to RD/AD/TB/PM/OC/DL to download**, сначала войдите в [DMM](https://debridmediamanager.com) в этом же браузере (см. [как войти](index.md#sign-in)), а потом откройте список снова.
2. DMM проверяет, какие релизы уже есть у вашего сервиса. Показываются только они, а то, что уже есть в вашей библиотеке, пропускается. Зелёная плашка **hidden** показывает, сколько релизов было скрыто.
3. При желании сузьте список:
   - **Movies** и **TV Shows** показывают только один тип. Цифры считают тайтлы, а не файлы.
   - **One per title** оставляет лучший релиз для каждого тайтла.
   - Зелёная плашка **other files** рядом с тайтлом показывает все его релизы.
   - **quick search on filename, hash, or id; supports regex** ищет по списку.
4. Нажмите кнопку в строке (**RD**, **TB**, **AD**, **PM**, **OC** или **DL**), чтобы добавить только этот релиз.
5. Или нажмите **RD Download** (**TB Download**, **PM Download** и так далее), чтобы добавить все показанные релизы. Число на кнопке — их количество. Загрузка начинается сразу, без вопроса «вы уверены?».

![Общий список хешей с открытыми фильмами в DMM, вход выполнен через Premiumize](../assets/dmm-hashlists/01-hash-list.webp)

На Real-Debrid, AllDebrid и TorBox кнопка **Show All** также показывает релизы, которых нет у вашего сервиса, а **Show Instant** возвращает только закэшированные.

**RD Download** добавляет только те релизы, которые уже есть у Real-Debrid, по одному в минуту, потому что Real-Debrid приостанавливает аккаунты, которые добавляют слишком быстро. Шестьдесят релизов займут около часа. Добавление идёт со страницы, поэтому держите вкладку открытой, пока не появится **Started 60 downloads.** TorBox и AllDebrid пропускают всё, что не закэшировано.

## Поделись своей библиотекой {#share-your-own-library}

1. На главной странице DMM нажмите **Library**.
2. Найдите или отметьте релизы, которыми хотите поделиться. Если ничего не отмечено, всё показанное будет передано.
3. Нажмите **Share List** (если отмечено три, кнопка будет называться **Share (3)**). Введите название в поле **Enter a title for the hash list** и нажмите **OK**.
4. DMM откроет адрес вашего нового списка на hashlists.debridmediamanager.com. Минуту-две может показываться 404, пока список публикуется. Обновите страницу и только после этого делитесь адресом.

![Окно с названием после нажатия Share List](../assets/dmm-hashlists/02-share-list.webp)

Открытые списки публичны. Любой, у кого есть адрес, может их открыть, а **Random hash list** может показать ваш список незнакомым людям. В списки попадают только названия, хеши и размеры: никогда не попадают ваш аккаунт, ваш ключ или адрес трекера.

Чтобы поделиться одним релизом без публикации чего-либо, нажмите значок «поделиться» в конце его строки в библиотеке (или **Hashlist** в его подробностях). DMM откроет список из одного релиза. Скопируйте адрес этой страницы и отправьте его.

## Если что-то не работает {#when-something-is-wrong}

| Что вы видите | Что делать |
|---|---|
| **Login to RD/AD/TB/PM/OC/DL to download** | Вы не вошли в DMM в этом браузере. Войдите и откройте список снова. |
| Всё **hidden**, и список выглядит пустым | Скрытые строки уже есть в вашей библиотеке, либо ваш сервис их не содержит. На Real-Debrid, AllDebrid или TorBox нажмите **Show All**. |
| **This hash list is still being published; refresh in a minute or two.** | Список опубликовали буквально только что. Подождите минуту-другую и обновите страницу. |
| **0 files** и нет строк | Этот список пустой. Нажмите **Next hash list** или **Random hash list**. |
| **Everything already downloaded** | Все показанные релизы уже есть в вашей библиотеке. |
| **Torrent not instant in TorBox; skipped.** или **Torrent not instant in AD; skipped.** | Этого торрента нет в кэше вашего сервиса, поэтому DMM пропустил его и не стал запускать загрузку. |
| **Skipping 3 items with no info hash — they cannot be shared.** | У этих строк (например, веб-загрузки TorBox) нет хеша, поэтому ими нельзя поделиться. Остальной список будет опубликован. |
| **Failed to generate hash list; try again soon.** | Не удалось опубликовать список. Попробуйте позже. |

Застряли? Спросите на форуме **dmm-support** в [Discord](https://discord.com/invite/7u4YjMThXP).

## Вопросы {#questions}

### Как добавить хэш-списки в свою библиотеку? {#how-do-i-add-hash-lists-to-my-own-library}

Откройте список, войдите в DMM через свой дебрид-сервис, затем нажмите кнопку вашего сервиса в строке или **RD Download** (или **Download** для вашего сервиса), чтобы скачать всё, что показано. См. [Add a list to your library](#add-a-list-to-your-library).

### Почему все элементы в моем хэш-списке скрыты? {#why-are-all-the-items-in-my-hash-list-hidden}

DMM скрывает то, что уже есть в вашей библиотеке, и то, что ваш сервис не держит в кэше. Количество скрытых показано в поле **hidden**. На Real-Debrid, AllDebrid или TorBox кнопка **Show All** показывает всё остальное.

### Почему сериалы не появляются в хэш-списке? {#why-dont-tv-shows-show-up-in-a-hash-list}

Нажмите **TV Shows** вверху списка. Если там написано **0 TV Shows**, значит, в этом списке нет сериалов: большинство общих списков состоят из фильмов. Сериалы, которых нет в вашем сервисе, тоже скрыты, поэтому попробуйте **Show All**.

### Почему добавление хэш-списка так медленное? {#why-is-adding-a-hash-list-so-slow}

На Real-Debrid DMM добавляет по одному релизу в минуту, чтобы Real-Debrid не приостановил ваш аккаунт. У остальных сервисов это идёт быстрее.

### Есть ли API для запросов к хэш-спискам? {#is-there-an-api-to-query-the-hash-lists}

Поискового API нет. Каждый общий список — это отдельный файл в публичном репозитории [hashlists](https://github.com/debridmediamanager/hashlists) на GitHub. Каждая страница ведёт в DMM, и сам список упакован в ссылку после `#` (JSON с названиями, хешами и размерами, сжатый через lz-string). Очень большой список лежит рядом в виде `lists/<id>.txt`.

### Если я поделюсь списком, поделюсь и моим аккаунтом? {#does-sharing-a-list-share-my-account}

Нет. Список содержит только названия релизов, хэши и размеры.
