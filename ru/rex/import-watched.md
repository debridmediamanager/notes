# Перенесите историю просмотров в rex {#bring-your-watch-history-to-rex}

rex начинает работу без истории просмотров. Он может скопировать просмотренные тайтлы, точки продолжения и звёздные оценки с другого сервера Plex.
Просмотренные тайтлы остаются просмотренными. Частично просмотренные тайтлы возвращаются в **Continue Watching**. Сериалы и сезоны заново подсчитывают свои эпизоды.

Запустите один раз с любого компьютера дома. Каждый, кто пользуется rex, может импортировать свою собственную историю.

## Перед началом {#before-you-start}

| Что нужно | Зачем |
|---|---|
| rex настроен, и ваша библиотека в нём, как в [rex с вашим приложением](any-source.md), [rex с вашими дополнениями Stremio](stremio.md) или [rex с zurg](with-zurg.md) | rex копирует историю только на те тайтлы, которые у него уже есть. Если ваша библиотека ещё заполняется, запустите импорт позже: он добавит только новое |
| rex nightly **2026.10.31 или новее** | Обновитесь, как описано в разделе [Updating у rex](any-source.md#updating) |
| Ваш старый сервер Plex, запущенный | rex читает историю с него. Запустите его снова, если вы остановили его при переходе на rex |
| Компьютер в домашней сети, с `curl` | Импорт работает только из домашней сети. Windows 10 и 11, macOS и Linux все уже имеют `curl` |

## 1. Скопируйте адрес вашего старого сервера {#1-copy-your-old-servers-address}

1. Откройте [app.plex.tv](https://app.plex.tv) в браузере и войдите как **вы сами**, то есть под тем аккаунтом, историю которого хотите перенести.
2. Выберите свой старый сервер и откройте любой фильм на нём.
3. Нажмите **⋯** (More), затем **Get Info**.
4. Нажмите **View XML** в левом нижнем углу окна **Media Info**, которое откроется. Появится новая вкладка с большим количеством текста.

   ![Окно Media Info, которое открывает Get Info, с View XML в левом нижнем углу](../assets/rex/40-plex-get-info.webp)
5. Скопируйте **весь адрес** из адресной строки этой вкладки.

Выглядит он так, всё в одну строку, и заканчивается на `X-Plex-Token=` и каким-то кодом:

```
https://192-168-1-5.0123456789abcdef.plex.direct:32400/library/metadata/1234?checkFiles=1&includeAllConcerts=1&X-Plex-Token=AbCdEfGh1234567890xy
```

Этот код и есть ваш **Plex token** для этого сервера. Он работает как пароль от вашего аккаунта Plex, поэтому никогда не вставляйте его в Discord, в пост с вопросом или на скриншот.

**Нет View XML на шаге 4?** Plex Web показывает эту кнопку только на сервере, который принадлежит вам. Если сервер вам дали другие, кнопки не будет. Тогда используйте инструменты разработчика в браузере на старом сервере, как в [шаге 2](#2-get-your-token-on-rex). Выберите любой запрос к старому серверу (в его адресе есть `plex.direct`). Щёлкните по нему правой кнопкой и скопируйте адрес: **Copy**, затем **Copy URL** в Chrome и Edge, или **Copy Value**, затем **Copy URL** в Firefox. Нужен именно этот адрес. В нём есть `X-Plex-Token=` с кодом и другие части `X-Plex-`, вставьте всё целиком.

## 2. Получите токен в rex {#2-get-your-token-on-rex}

Сервер rex вам открыт по общему доступу, поэтому **Get Info** для rex не показывает **View XML**: Plex Web показывает его только владельцу сервера. Вместо этого возьмите токен из браузера, так как app.plex.tv отправляет его rex:

1. На app.plex.tv, оставаясь вошедшим под своим аккаунтом, откройте инструменты разработчика браузера: **F12** или **⌥ ⌘ I** на Mac. В Safari сначала включите **Show features for web developers** в **Settings**, **Advanced**.
2. Откройте вкладку **Network** и введите `X-Plex-Token` в поле фильтра.
3. Откройте любой фильм на сервере **rex**. Список заполнится запросами.
4. Нажмите на тот, чей адрес относится к rex: при rex-direct в нём есть `rex-direct.debridmediamanager.com`, либо это HTTPS-адрес, который вы настроили сами. Не тот, что ведёт на `plex.tv`.
5. Скопируйте значение `X-Plex-Token`: Chrome и Edge показывают его в разделе **Payload**, Firefox в **Request**. Или скопируйте адрес запроса и возьмите часть после `X-Plex-Token=` до следующего `&`.

Это другой код, не тот, что в шаге 1: каждый сервер выдаёт вашему аккаунту свой. rex использует этот токен, чтобы знать, чья это история.

## 3. Запустите импорт {#3-run-the-import}

На домашнем компьютере запусти это, вставив свои два значения. `192.168.1.20` — это LAN IP rex, как в гайдах по настройке: вставь свой адрес на его место.

```bash
curl -d "ADDRESS-FROM-STEP-1" "http://192.168.1.20:32400/rex/import-watched?X-Plex-Token=TOKEN-FROM-STEP-2"
```

В Windows откройте **PowerShell** и введите `curl.exe` вместо `curl`. Оставь обе пары двойных кавычек: адрес из шага 1 содержит символы `&`, и без кавычек команда сломается.

Занимает несколько секунд, для большой библиотеки дольше: rex читает каждый фильм и каждый эпизод на старом сервере.

**Что ты должен увидеть.** Одна строка такого вида:

```json
{"watched":412,"inProgress":7,"rated":38,"alreadyHere":0,"notInRex":55}
```

| Число | Что значит |
|---|---|
| `watched` | Тайтлы, которые rex отметил как просмотренные, со счётчиком просмотров и датой со старого сервера |
| `inProgress` | Тайтлы, которые ты посмотрел частично: они продолжатся с того места, где ты остановился |
| `rated` | Тайтлы, которым поставлена звёздная оценка |
| `alreadyHere` | Тайтлы, которые ты уже посмотрел или начал в rex. rex оставляет то, что у него уже есть, и ничего там не меняет |
| `notInRex` | Тайтлы, по которым на старом сервере есть история, но в rex их нет или они не совпадают как один и тот же тайтл |

Открой приложение Plex снова (или обнови app.plex.tv), чтобы увидеть результат.

## Запускайте его снова в любое время {#run-it-again-any-time}

Повторный запуск ничего не меняет в том, что у вас уже есть, так что запускайте его, когда в библиотеку придёт что-то новое. Если запустить сразу второй раз, в выводе будет `"watched":0`, а предыдущие результаты окажутся под `alreadyHere`.

## Что не копируется {#what-is-not-copied}

- История всех остальных пользователей на вашем старом сервере. Каждый человек запускает импорт со своими двумя токенами.
- Список истории воспроизведения, плейлисты и коллекции с вашего старого сервера.
- Звёздные рейтинги целых сериалов и сезонов. Рейтинги фильмов и эпизодов копируются.
- Тайтлы в библиотеке, у которой агент на старом сервере не **Plex Movie** и не **Plex TV Series** (более старые агенты, например Plex Movie (Legacy) и TheTVDB). rex находит тайтл по id, который выдают текущие агенты Plex, а старые агенты присваивают другой id, поэтому такие тайтлы учитываются в `notInRex`.

## Если не работает {#if-it-does-not-work}

| Что вы видите | Что делать |
|---|---|
| `that address has no X-Plex-Token: copy it whole from the tab View XML opens` | Вставленный адрес обрывается до токена. Скопируйте его заново из адресной строки или инструментов разработчика и вставьте целиком |
| `send the address View XML opens on your old Plex server, starting http:// or https://` | В кавычках после `-d` оказалось не то, что нужно. Нужен адрес, который открывается из View XML, он должен начинаться с http:// или https:// |
| `... refused the token: copy the address from View XML again` | Старый сервер не принял токен. Повторите шаг 1, при необходимости с инструментами разработчика, если сервер вам передали |
| `could not reach https://...` | rex не смог подключиться к вашему старому серверу. Он должен быть запущен, и **машина rex** должна до него достучаться: rex читает данные с него, а не ваш компьютер |
| `run the import from your home network` | Вы отправили команду на внешний адрес rex. Используйте LAN IP rex, как в шаге 3 |
| Страница `Unauthorized` | rex не принял токен из шага 2. Скопируйте его заново из запроса к rex, а не к `plex.tv` |
| `notInRex` намного выше, чем вы ожидаете | Большая часть библиотеки ещё не попала в rex, или ваша старая библиотека использует один из старых агентов Plex. Запустите снова, когда библиотека полностью попадёт в rex |

Всё ещё не получается? Спросите в форуме **rex-support** в [Discord](https://discord.com/invite/7u4YjMThXP). В [Получении помощи](../guides/remote-help.md) написано, что нужно указать.
