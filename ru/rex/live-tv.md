# Живое ТВ с rex {#live-tv-with-rex}

Вот как rex показывает каналы-аддоны в **Live TV** в Plex Web и Plex for Android: с гидом и разделом What's On. Выберите канал, и он сразу начнёт играть. [rex-live-sports](https://github.com/debridmediamanager/rex-live-sports) готов к работе с сервером live-спорта. Для IPTV M3U и XMLTV гида см. [Tutorial: an IPTV addon](addon-iptv.md).

Что вы получаете:

- **Гид.** Все каналы с их номерами, с тем, что идёт сейчас и что будет дальше.
- **What's On.** Что идёт прямо сейчас, что начнётся позже и какие фильмы скоро выйдут.
- **Поиск.** Название передачи находит её в Live TV, а также в ваших библиотеках.
- **Просмотр.** Выберите канал, и он будет идти в прямом эфире. Канал не сохраняет точку продолжения и никогда не помечается как просмотренный.
- **Сетка, как у телеоператора.** rex-live-sports начинается с американской сетки: около 30 спортивных сетей с номерами, которые никогда не меняются (ESPN — 2, CBS — 7), расписание игр ESPN на этих каналах и слот-каналы (`NFL 1`, `NBA 1` и так далее), которые показывают список игр дня до их начала и играют каждую в прямом эфире. Есть также британская и немецкая сетки.
- **Библиотека тоже.** Каналы остаются в собственной библиотеке **Live Sports**, разложенные по коллекции для каждой группы.

## Перед началом {#before-you-start}

| Вам нужно | Зачем |
|---|---|
| Ночная сборка rex с датой 2026.11.02 или новее | Live TV появился в этой сборке |
| rex настроен, как в [rex with your own app](any-source.md), с [Converting video](any-source.md#converting-video-optional) | rex конвертирует каждый канал, пока вы его смотрите (копия, дешёвая операция) |
| Сервер live-sports на машине с rex или в вашей домашней сети | rex-live-sports берёт каналы с него |
| Docker | Нужен для live-sports в Шаге 2. В его [README](https://github.com/yowmamasita/live-sports-public) есть другие способы |
| Python 3.9 или новее, `git`, `ffmpeg` и `ffprobe` на машине с rex | rex-live-sports проверяет поток каждого канала с помощью ffprobe и рисует постер с помощью ffmpeg |

## Шаг 1. Установите rex и добавьте его в аккаунт Plex {#step-1-install-rex-and-add-it-to-a-plex-account}

Следуйте [rex со своим приложением](any-source.md):

1. [Шаг 1. Установите rex](any-source.md#step-1-install-rex), включая определение LAN IP rex. На этой странице он записан как `192.168.1.20`: подставьте свой.
2. [Шаг 3. Добавьте его в аккаунт Plex](any-source.md#step-3-add-it-to-a-plex-account): зарегистрируйте rex в новом аккаунте и откройте к нему доступ из своего.
3. [Конвертация видео](any-source.md#converting-video-optional).

Шаги 2 и 4 там пропустите: rex-live-sports — это ваше приложение.

## Шаг 2. Запустите сервер живого спорта {#step-2-start-a-live-sports-server}

**Что делает.** Запускает live-sports, который находит спортивные каналы и каждые несколько минут проверяет, какие из них сейчас идут.

```bash
docker run -d --name live-sports --restart unless-stopped -p 8765:8765 ghcr.io/yowmamasita/live-sports:latest
```

**Что вы должны увидеть.** По адресу `http://192.168.1.20:8765` в браузере открывается панель управления live-sports. Первая проверка каждого канала занимает несколько минут.

## Шаг 3. Установите rex-live-sports {#step-3-install-rex-live-sports}

**Что делает.** Скачивает rex-live-sports в `~/rex-live-sports` на машине с rex и запускает его.

+++ Linux
```bash
sudo apt install -y git python3 ffmpeg
cd ~ && git clone https://github.com/debridmediamanager/rex-live-sports
cd ~/rex-live-sports && cp config.example.json config.json
```

В `config.json` задайте `live_sports_url` равным `http://192.168.1.20:8765`, а `rex_url` равным `http://192.168.1.20:32400`. Затем:

```bash
mkdir -p ~/.config/systemd/user
cp ~/rex-live-sports/rex-live-sports.service ~/.config/systemd/user/
systemctl --user daemon-reload && systemctl --user enable --now rex-live-sports
journalctl --user -u rex-live-sports -f
```
+++ macOS
```bash
brew install ffmpeg
cd ~ && git clone https://github.com/debridmediamanager/rex-live-sports
cd ~/rex-live-sports && cp config.example.json config.json
```

В `config.json` задайте `live_sports_url` равным `http://192.168.1.20:8765`, а `rex_url` равным `http://192.168.1.20:32400`. Затем:

```bash
python3 rex_live_sports.py
```

Оно работает, пока открыто окно Terminal.
+++

**Что должно появиться.** Примерно такая строка:

```
INFO relay on http://127.0.0.1:9983/, live-sports at http://192.168.1.20:8765, rex at http://192.168.1.20:32400
```

Пока не закончится первая проверка live-sports, в логе будет `live-sports lists no channel that plays yet`. Потом первая синхронизация проверяет поток каждого канала из сетки, которую знает live-sports: примерно минута на 30 каналов, и в логе появится:

```
INFO pushed 38 of 30 channels, 38 with their Live TV channel: ...
```

Это 30 каналов сетки, которые знает live-sports, плюс слоты с матчем на этот день. Синхронизация повторяется каждые пять минут, и проверяются только те каналы, которые за этот день ещё не смотрели.

## Шаг 4. Откройте общую библиотеку и Живое ТВ {#step-4-share-the-library-and-open-live-tv}

Библиотека **Live Sports** новая, поэтому пока ни в одном шеринге её нет. Войди под новым аккаунтом и добавь её в шеринг своего аккаунта и всех остальных в **Manage Library Access** ([Поделиться rex](sharing.md)). Шеринг даёт аккаунту доступ к Live TV, если ты не отключил это для него.

Потом открой приложение Plex под своим аккаунтом:

- **Plex Web**: **Live TV & DVR** есть в боковом меню, рядом с библиотеками rex.
- **Plex for Android**: вкладка **Live TV** внизу экрана, сверху выбран rex; **Live TV & DVR** тоже есть в списке вместе с библиотеками rex.

**Что ты должен увидеть.** Вверху **Guide** и **What's On**. В гиде каждый канал указан под своим номером с тем, что сейчас в эфире. Выбери передачу и нажми **Watch Now**.

## Каналы, номера и программа передач {#channels-numbers-and-guides}

`config.json` задаёт лайнап: `lineups/us.json` в исходном виде, а `lineups/uk.json` или `lineups/de.json` для британских или немецких сетей. Канал из лайнапа стоит на своём номере, а в live-sports есть его копия, которая и играет.

Американская сеть получает игры из расписания ESPN (`Chicago Bears at Seattle Seahawks`, с начала матча на обычную длительность для вида спорта: NFL, студенческий футбол, NBA, NHL, MLB, крупные европейские лиги, MLS и F1). ESPN знает только американские вещатели, поэтому британские и немецкие сети берут программу передач, которую для канала с таким же названием даёт [epgshare01](https://epgshare01.online/), как и любой канал вокруг своих игр. Канал, которого нет ни в одном гиде, показывает собственное название блоками по шесть часов.

Слоты идут после сетей: `NFL 1`–`NFL 10` на `700.1`–`700.10`, `NBA 1`–`NBA 6` начиная с `701.1`, затем NHL, MLB, Soccer и F1. Каждая игра дня попадает в первый свободный слот своего вида спорта, поэтому гид показывает её ещё до начала. С 15 минут до начала и до конца матча слот играет поток live-sports, в котором есть эта игра (ищется по названиям обеих команд). Между играми слот ничего не показывает. Слот появляется в списке при первом показе игры.

Без лайнапа (`"lineup": ""` в `config.json`) вместо этого в списке идут все каналы групп `Live:` и `Sports` из live-sports, нумеруясь по группам: `100.1`, `100.2` для первой группы, `101.1` для следующей, чтобы не пересекаться с низкими номерами, которые занимают тюнер или другой источник. Канал сохраняет свой номер, пока live-sports перечисляет его хотя бы раз в неделю. Каналы Pluto TV получают собственное расписание Pluto TV и не добавляются, пока вы их не запросите: `"groups": ["Live:", "Sports", "Pluto:"]`. Все настройки описаны в [README](https://github.com/debridmediamanager/rex-live-sports#settings) rex-live-sports.

## Обновление {#updating}

```bash
cd ~/rex-live-sports && git pull && systemctl --user restart rex-live-sports
```

На macOS остановите его через Ctrl+C, выполните `git pull` в `~/rex-live-sports` и запустите снова.

## Чего он не умеет {#what-it-cannot-do}

- **Записи не работают.** В Plex Web и Plex for Android нет кнопки Record.
- **Гиды сопоставляются по названию.** Канал может получить гид другого потока того же бренда, а многим событийным каналам гид не достаётся вовсе.
- **Слот ищет поток игры по названиям команд.** Поток с другим названием (`nfl ravens`) не находится, а игра, для которой нет ни одного потока, есть в гиде, но не воспроизводится.
- **Plex записывает передачу без номера эпизода как фильм**, как и в любом ТВ-гиде, поэтому совпадения также показываются в разделе What's On во вкладке фильмов.
- **Live TV проверяли в Plex Web и Plex for Android.** Другие приложения Plex не тестировались.
- **Любой, кто может достучаться до адреса rex-live-sports, может смотреть через него.** Оставьте `listen` на `127.0.0.1`.

Чтобы добавить свои каналы с уже имеющимся гидом, см. [Создание аддонов для rex](addons.md#live-tv).
