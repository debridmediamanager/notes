# rex для Android {#rex-for-android}

rex — это медиасервер для приложений Plex, который не хранит никаких файлов. rex для Android запускает его на телефоне, планшете, Android TV, Google TV или Fire TV, без компьютера. Приложения Plex на ваших устройствах находят его, как любой другой сервер Plex, и воспроизводят из него.

То, что можно смотреть, берётся из **аддонов**. Изначально в нём есть фильмы из публичного достояния Internet Archive. Другие аддоны, например ваши аддоны Stremio, YouTube и Spotify, устанавливаются прямо из приложения, как только вы добавите их репозиторий.

rex для Android бесплатен. Хотите добавить в него и свои аккаунты дебрид-сервисов и Usenet? zurg+rex, Plex-сервер на вашем телефоне со встроенным zurg, доступен по спонсорской подписке: см. [zurg+rex для Android](../zurg/guides/android.md).

## Перед началом {#before-you-start}

| Что нужно | Зачем |
|---|---|
| Устройство с Android 8.0 или новее | Телефон, планшет, Android TV, Google TV или Fire TV. Fire TV на Vega OS, например Fire TV Stick 4K Select, не запускают приложения для Android |
| Аккаунт Plex | rex появляется в приложениях Plex, в которые вы вошли под этим аккаунтом. Бесплатного аккаунта достаточно |
| Приложение Plex на устройстве, с которого вы смотрите | Plex для Android, Android TV, iPhone, смарт-ТВ, Plex Web, Plexamp |

## Шаг 1. Установите приложение {#step-1-get-the-app}

Выберите один способ. Каждый обновляет rex по-своему.

| Способ | Подходит для |
|---|---|
| Google Play | Телефоны, планшеты, Android TV и Google TV. Скоро |
| Amazon Appstore | Fire TV и планшеты Fire. Скоро |
| [Obtainium](#with-obtainium) | Телефоны и планшеты. Сообщает, когда выходит обновление |
| [Downloader](#with-downloader-on-fire-tv) | Fire TV и ТВ-приставки |
| [Файл с GitHub](#the-file-from-github) | Любое устройство. Обновления вы устанавливаете сами |

**Способы нельзя смешивать.** Google Play, Amazon Appstore и файл с GitHub (который также устанавливают Obtainium и Downloader) подписаны по-разному, поэтому один не может обновить другой. Чтобы переключиться, удалите rex, повторите Шаги 2 и 3 и установите аддоны заново.

**Они стартуют с разных аддонов.** Версия с GitHub стартует с уже добавленным репозиторием [rex-addons](https://github.com/debridmediamanager/rex-addons). Версии из магазинов стартуют только с аддоном Internet Archive; добавьте rex-addons сами (см. [Дополнения](#addons)), если он вам нужен.

### С помощью Obtainium {#with-obtainium}

[Obtainium](https://obtainium.imranr.dev/) устанавливает приложения с GitHub и следит за их обновлениями.

1. Установите Obtainium и откройте его один раз.
2. На том же устройстве откройте [rex.debridmediamanager.com/obtainium](https://rex.debridmediamanager.com/ru/obtainium). Obtainium откроется и предложит **Import app**. Нажмите **Continue**.
3. Нажмите **rex**, затем **Install**. Obtainium сам выберет файл под процессор вашего устройства.
4. В первый раз Android откроет **Install unknown apps** для Obtainium. Включите **Allow from this source** и вернитесь назад.
5. Нажмите **Install**. Если Play Protect покажет **App scan recommended**, нажмите **Scan app**, затем **Install**.

Когда выйдет новая версия, рядом с rex появится кнопка **Update**.

### С помощью Downloader на Fire TV {#with-downloader-on-fire-tv}

1. На Fire TV установите **Downloader** от AFTVnews из Appstore.
2. Откройте его, выберите поле адреса и введите `rex.debridmediamanager.com/tv`. Нажмите **Next**. Начнётся загрузка `rex-android-armeabi-v7a.apk`.
3. Нажмите **Install**. В первый раз Fire TV вместо этого откроет **Developer options**. Выберите **Install unknown apps**, затем **Downloader**, чтобы там появилось **ON**. Дважды нажмите Back и снова нажмите **Install**.
4. Нажмите **Install**, затем **Open**.

Чтобы обновить, повторите шаги со 2 по 4. Короткий код для Downloader скоро появится.

### Файл с GitHub {#the-file-from-github}

На устройстве скачайте файл для его процессора. Каждая ссылка всегда ведёт на самую новую версию:

| Ваше устройство | Скачать |
|---|---|
| Большинство телефонов, планшетов и ТV-приставок (64-бит) | [rex-android-arm64-v8a.apk](https://github.com/debridmediamanager/rex-android/releases/latest/download/rex-android-arm64-v8a.apk) |
| Fire TV и старые или дешёвые 32-битные приставки | [rex-android-armeabi-v7a.apk](https://github.com/debridmediamanager/rex-android/releases/latest/download/rex-android-armeabi-v7a.apk) |
| Эмуляторы на ПК | [rex-android-x86_64.apk](https://github.com/debridmediamanager/rex-android/releases/latest/download/rex-android-x86_64.apk) |

Все версии и их изменения есть на [странице релизов](https://github.com/debridmediamanager/rex-android/releases). Не уверены? Сначала попробуйте `arm64-v8a`. Один файл подходит и для телефонов, и для телевизоров.

Откройте скачанный файл. Android скажет, что **не разрешает установку приложений из неизвестных источников**. Нажмите **Settings**, включите **Allow from this source**, вернитесь назад и нажмите **Install**.

Чтобы обновиться, установите новый файл поверх старого. rex запустится заново сам, а ваш вход в аккаунт и дополнения останутся на месте.

**Что вы должны увидеть.** **rex** в списке ваших приложений.

## Шаг 2. Запустите rex {#step-2-start-rex}

**rex**'ни откройте. На первом экране написано **Welcome to rex.**

1. Нажмите **Allow notifications**, затем **Allow**. rex работает в фоне и показывает уведомление, которым его можно остановить.
2. Нажмите **Let rex keep running in the background**. В открывшемся списке выберите **rex** и укажите **Don't optimize**. На новых версиях Android это **Allow background usage**, затем **Unrestricted**. Вернитесь в rex. Обе кнопки теперь начинаются с ✓.
3. **Name** — это имя, под которым приложения Plex показывают этот сервер. При желании поменяйте его.
4. Оставьте **Port** как есть: `32400`. Если на этом устройстве уже работает другой сервер Plex, rex покажет **Another app here already uses this port, maybe a Plex server. Try 32500.** Тогда введите `32500`.
5. Нажмите **Start rex**.

**Что должно появиться.** **2 / 2** и **Sign in to Plex.**

| Первый экран | Страница фильма в приложении Plex (шаг 4) |
|---|---|

## Шаг 3. Войдите в Plex {#step-3-sign-in-to-plex}

Нажмите **Sign in to Plex**. rex покажет код: **On any phone or computer, go to plex.tv/link and enter** it.

- **На телефоне или планшете** ваш браузер тоже откроет страницу Plex, где написано **rex for Android would like to sign in to your Plex account**. Войдите там.
- **На телевизоре** откройте [plex.tv/link](https://plex.tv/link) на телефоне или компьютере, войдите и введите код.

Используйте тот аккаунт, в который вошли ваши приложения Plex. Можно нажать **Skip for now** и войти позже из **Status**.

![rex for Android on a TV showing the code to enter at plex.tv/link](../assets/rex/android-tv-signin.webp)

**Что должно появиться.** **Signed in. rex shows up in the Plex apps as** название вашего сервера. Нажмите **Done**. **Status** покажет **RUNNING** и **Ready for the Plex apps.**

## Шаг 4. Смотрите в приложении Plex {#step-4-watch-in-a-plex-app}

Откройте любое приложение Plex, в которое вы вошли под той же учётной записью. Если Plex установлен на этом устройстве, в разделе **Status** есть кнопка **Open Plex**.

В приложении Plex для Android откройте **Libraries**, затем **All Libraries**, и в разделе с именем вашего сервера выберите **Movies**. В других приложениях Plex библиотека тоже отображается под именем сервера.

Первая синхронизация Internet Archive занимает некоторое время: примерно полчаса на нашем тестовом устройстве, пока rex проверяет каждый фильм. **Status** показывает **Syncing**, пока процесс не завершится, а затем количество, например **Ready · 97 titles**. Нажмите play на любом фильме.

![Приложение Plex на телевизоре воспроизводит короткометражку Чаплина 1914 года из rex на том же телевизоре](../assets/rex/android-tv-playing.webp)

## Дополнения {#addons}

**Addons** показывает, что вы установили. У каждого указаны его тайтлы и время последней синхронизации. Его кнопки: **Sync now**, **Settings**, **Log** и **Remove**; на телефоне проведите рядом с кнопками в сторону, чтобы увидеть все. Переключатель **Enabled** выключает аддон, но не удаляет его.

Аддоны берутся из **repositories**: git-репозиториев, в которых лежат аддоны. Аддон Internet Archive уже установлен. Чтобы получить больше, добавьте [rex-community-addons](https://github.com/debridmediamanager/rex-community-addons) (см. **Add a repository** ниже). Он предлагает:

| Addon | Что добавляет |
|---|---|
| Stremio addons | Каталоги фильмов и сериалов ваших аддонов Stremio, которые воспроизводятся из стримов, выданных вашими стрим-аддонами |
| YouTube | Ваши плейлисты YouTube. Входите по коду |
| Spotify | Ваша библиотека Spotify как музыка для Plex и Plexamp. Нужен аддон YouTube, с выполненным входом |

**Установка.** В разделе **Repositories** нажмите **Addons** рядом с репозиторием, а затем **Install** под нужным аддоном. rex покажет, к каким сайтам он сможет обращаться, и спросит ещё раз, после чего начнёт синхронизацию.

**Вход.** Аддон, которому нужен ваш аккаунт, пишет **Sign in to start.** Нажмите его кнопку **Sign in**: откройте указанную страницу на любом устройстве и введите показанный код.

**Добавление репозитория.** В разделе **Add a repository** введите его ссылку (достаточно `github.com/user/repo`) и нажмите **Add**. Устанавливайте только то, что делают люди, которым вы доверяете. Чтобы написать свой аддон, см. [rex-addons](https://github.com/debridmediamanager/rex-addons).

## Смотрите на других устройствах дома {#watch-on-other-devices-at-home}

Каждое приложение Plex, вошедшее в тот же аккаунт, находит rex в вашей домашней сети по имени: ваш телевизор, другой телефон, Plex Web на компьютере. **Status** показывает адрес rex дома, например `http://192.168.1.20:32400`.

Чтобы дать семье смотреть со своими аккаунтами Plex, см. [Поделитесь rex с семьёй и друзьями](sharing.md).

## Держите его запущенным {#keep-it-running}

- rex работает, пока устройство включено. Кнопка **Stop** в уведомлении останавливает его; в **Status** есть **Start**, **Stop** и **Restart**.
- В **Settings** включите **Start when this device turns on**. Иначе после перезагрузки откройте rex и нажмите **Start**.
- Некоторые телефоны всё ещё останавливают фоновые приложения. [Don't kill my app](https://dontkillmyapp.com/) объясняет, что нужно вашему приложению.
- Чтобы переименовать сервер, откройте в приложении Plex **Settings**, **General** и измените **Friendly name**.

## Ограничения {#limits}

- **Воспроизведение дома.** Вне дома приложениям Plex нужен HTTPS-адрес, который ведёт на устройство, а для этого на роутере нужно настроить проброс портов на него. См. [Использование вне дома](any-source.md#use-it-outside-your-home-optional).
- **Устройство и есть сервер.** Оставляйте его включённым, подключённым по Wi-Fi или Ethernet и в розетке. Конвертация видео для плеера, который не может воспроизвести файл, использует собственное аппаратное обеспечение устройства и может быть медленной на дешёвой приставке.
- **Только то, что приносят аддоны.** На самом устройстве нет библиотеки файлов.

## Устранение неполадок {#troubleshooting}

| Что вы видите | Что делать |
|---|---|
| **App not installed as app isn't compatible with your phone.** | Вы выбрали не тот файл для процессора. Попробуйте другой из таблицы в разделе [Файл с GitHub](#the-file-from-github) |
| **Another app here already uses this port, maybe a Plex server. Try 32500.** | Введите `32500` как порт |
| **Use a number from 1024 to 65535** | Порт должен быть числом из этого диапазона |
| Сервера нет в приложении Plex | Войдите в приложение Plex под той же учётной записью, что и на Шаге 3, и держите оба устройства в одной домашней сети |
| Библиотека пуста | Первая синхронизация ещё идёт: подождите, пока **Status** не покажет количество тайтлов |
| **Sign in needed** под дополнением | Нажмите его кнопку **Sign in** и введите код |
| **Needs an update** под дополнением | Эта версия приложения больше не может работать с этой копией дополнения. Обновите его репозиторий и нажмите **Update**. Его тайтлы пока останутся на месте |
| **That isn't a repository link. Try github.com/user/repo.** | Введите ссылку на репозиторий, например `github.com/user/repo` |
| **no public git repository there (it asks for a login)** | Ссылка неверная или репозиторий приватный. Проверьте её в браузере |
| rex останавливается, когда экран выключен | Повторите настройку фона из Шага 2 и посмотрите [Не убивай моё приложение](https://dontkillmyapp.com/) |

**Logs** показывает, что недавно писали rex и дополнения, при этом ключи и пароли скрыты. Если поддержка попросит логи, нажмите **Send logs to support**: перед отправкой вы увидите всё содержимое, затем нажмите **Send** и опубликуйте полученный код.

Что приложение отправляет и куда, написано в его [политике конфиденциальности](android-privacy.md).
