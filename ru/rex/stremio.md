# rex с вашими аддонами Stremio {#rex-with-your-stremio-addons}

[rex-stremio](https://github.com/debridmediamanager/rex-stremio) превращает каталоги аддонов Stremio в библиотеки rex. Фильмы, сериалы и живые каналы потом воспроизводятся в приложениях Plex. Ничего не скачивается. Когда кто-то нажимает play, rex-stremio запрашивает у стрим-аддона ссылку, а rex её проигрывает.

Для этого не нужен спонсорский доступ к DMM. rex и rex-stremio бесплатные. Подключай стрим-аддоны, которые возвращают ссылки, обычно через твой собственный аккаунт debrid.

Что ты получаешь:

- **Библиотеки.** Фильмы попадают в **Stremio Films**, сериалы в **Stremio Shows**, а каналы живого ТВ из аддона в библиотеку **Live TV**, если только ты сам не назовёшь библиотеку для каталога. Эта библиотека представляет собой список каналов. Они не появляются в гиде Live TV в приложениях Plex.
- **Коллекции.** Если несколько каталогов фильмов ты направляешь в одну библиотеку и ставишь галочку **Catalogs as collections**, получается одна библиотека с коллекцией для каждого каталога. Фильм, который есть в нескольких каталогах, будет там только один раз.
- **Plex знает названия.** Фильмы и эпизоды передаются в rex с их IMDb id, поэтому после того как rex подключён к аккаунту Plex, приложения показывают обычные названия, постеры и описания. Названия, которые известны только аддону, и живые каналы сохраняют названия и картинки от аддона.

## Перед началом {#before-you-start}

| Вам нужно | Зачем |
|---|---|
| Машина, которая всегда включена, Linux или macOS, для rex и rex-stremio вместе | rex-stremio — это одна программа на Python, которая работает рядом с rex. Служба ниже рассчитана на Linux; [Docker](#in-docker) тоже подойдёт |
| Python 3.9 или новее, `git` и `ffprobe` | rex-stremio один раз проверяет поток каждого тайтла с помощью ffprobe, потому что rex должен знать, что находится в файле, прежде чем его можно будет воспроизвести. Если у вас есть ключ API DMM, поток debrid для торрента, который DMM уже проверила, уже содержит результат probe и эту проверку пропускает; всё остальное проверяется через probe |
| Stream-аддоны, которые отдают ссылки, а не торренты | rex воспроизводит файлы. Укажите свой debrid-сервис в аддоне, чтобы он отдавал ссылки |
| Новый аккаунт Plex, созданный специально для rex | Как в настройке rex: rex привязывается к нему и предоставляется доступ вашему основному аккаунту |

## Шаг 1. Установите rex и добавьте его в аккаунт Plex {#step-1-install-rex-and-add-it-to-a-plex-account}

Следуйте инструкции [rex with your own app](any-source.md):

1. [Step 1. Install rex](any-source.md#step-1-install-rex), включая поиск LAN IP rex. Используйте это имя в каждой команде.
2. [Step 3. Add it to a Plex account](any-source.md#step-3-add-it-to-a-plex-account): зарегистрируйте rex на новом аккаунте и поделитесь им со своим.

Шаги 2 и 4 там пропустите: rex-stremio — это ваше приложение.

Живые каналы и аддоны, чьи потоки — это плейлисты `.m3u8`, работают только через конвертацию видео в rex. Для них также настройте [Converting video](any-source.md#converting-video-optional) на машине с rex. Фильмы и серии, которые отдаются файлами (`.mkv`, `.mp4`), ничего больше не требуют.

## Шаг 2. Установите rex-stremio {#step-2-install-rex-stremio}

**Что это делает.** Скачивает rex-stremio в `~/rex-stremio` на машине с rex и запускает его как сервис.

+++ Linux
```bash
sudo apt install -y git python3 ffmpeg
cd ~ && git clone https://github.com/debridmediamanager/rex-stremio
mkdir -p ~/.config/systemd/user
cp ~/rex-stremio/rex-stremio.service ~/.config/systemd/user/
systemctl --user daemon-reload && systemctl --user enable --now rex-stremio
journalctl --user -u rex-stremio -f
```
+++ macOS
```bash
brew install ffmpeg
cd ~ && git clone https://github.com/debridmediamanager/rex-stremio
cd ~/rex-stremio && python3 rex_stremio.py
```

Он работает, пока открыто окно Terminal.
+++

**Что должно появиться.** Примерно такая строка:

```
... INFO relay and settings on http://127.0.0.1:9982/, 0 catalog(s), rex at http://127.0.0.1:32400
```

Страница настроек rex-stremio и адрес, с которого rex читает видео, находятся на `127.0.0.1:9982`, поэтому до них дотянется только эта машина.

## Шаг 3. Добавьте свои аддоны {#step-3-add-your-addons}

Откройте `http://127.0.0.1:9982/` в браузере на машине с rex. Нет экрана? С вашего компьютера выполните `ssh -L 9982:127.0.0.1:9982 you@<rex's LAN IP>`, затем откройте тот же адрес, пока SSH-сессия открыта.

1. В разделе **Addons** вставьте ссылку на манифест дополнения, как в Stremio, и нажмите **Add**. Сделайте это для:
   - **Catalogs**, например Cinemeta: `https://v3-cinemeta.strem.io/manifest.json`.
   - **Streams**: дополнение, которое находит релизы и воспроизводит их через ваш debrid-сервис. Откройте его страницу настроек, выберите свой debrid-сервис, вставьте API-ключ и скопируйте ссылку на манифест, которую оно создаст. Если оно предлагает только кэшированные результаты, выберите именно это. Ссылка содержит ваш debrid-ключ, так что никому её не передавайте.

   ![Раздел Addons в rex-stremio с добавленными Cinemeta и Public Domain Movies](../assets/rex/90-stremio-addons.webp)

2. В разделе **Catalogs** отметьте нужные каталоги. Укажите библиотеку, в которую попадёт каждый, и задайте **How many**: сколько фильмов, эпизодов или каналов взять. Если нужна одна библиотека, где каждый каталог становится коллекцией, укажите для каталогов одну и ту же библиотеку и отметьте **Catalogs as collections**.
3. В разделе **Streams** задайте **Highest resolution** и **Largest file**, которые хотите воспроизводить, или оставьте значения **any**.
4. В разделе **rex** укажите адрес `http://<rex's LAN IP>:32400`.
5. Если вы спонсируете DMM, вставьте свой DMM API-ключ в разделе **DMM** (после спонсорства его покажет [gatekeeper](https://gatekeeper.debridmediamanager.com/)). Debrid-поток торрента, для которого DMM уже хранит пробу, пропускает свою проверку. Всё остальное проверяется, и то, что rex-stremio проверяет в файлах торрента (но никогда не в обычных HTTP-потоках или HLS-плейлистах), отправляется обратно в DMM для следующего спонсора (`share_probes: false` в `config.json` это отключает). Нажмите **Save and sync**.

![Разделы Catalogs, Streams, rex и DMM в rex-stremio с кнопкой Save and sync](../assets/rex/91-stremio-catalogs-rex.webp)

**Что вы должны увидеть.** В логе rex, как в [шаге 4 из rex со своим приложением](any-source.md#step-4-connect-your-app):

```
INFO    SOURCES PUT /rex/sources/stremio -> 200
INFO    FEED stremio upsert: ...
```

Названия появляются в rex по мере проверки каждого, а не когда проверен весь каталог, и rex-stremio проверяет несколько сразу. Синхронизация повторяется каждые шесть часов и после каждого сохранения.

## Шаг 4. Поделитесь новыми библиотеками и смотрите {#step-4-share-the-new-libraries-and-watch}

Библиотеки, которые создает rex-stremio, новые, поэтому ваш собственный аккаунт пока их не видит. Поделитесь ими со своим аккаунтом, как в [шаге 3](any-source.md#share-it-with-your-own-account), войдя под новым аккаунтом, а также с любым другим, с кем вы делитесь rex.

Затем откройте приложение Plex под своим аккаунтом и нажмите play на чем-нибудь. rex-stremio в этот момент запрашивает ссылку у ваших стрим-аддонов, и rex ее воспроизводит. Чтобы смотреть вне дома или в app.plex.tv, дайте rex собственный адрес: [Use it outside your home](any-source.md#use-it-outside-your-home-optional).

## Обновление {#updating}

```bash
cd ~/rex-stremio && git pull && systemctl --user restart rex-stremio
```

На macOS останови его через Ctrl+C, выполни `git pull` в `~/rex-stremio` и запусти снова.

## Чего он не умеет {#what-it-cannot-do}

- **Эпизоды нумеруются так же, как их нумерует Cinemeta.** У некоторых сериалов это отличается от нумерации TMDB, по которой ориентируется rex, так что эпизод может попасть не туда.
- **Счётчик считает эпизоды** для каталога сериалов, а не сами сериалы.
- **Включение и выключение Catalogs as collections** отправляет тайтлы в rex заново как новые, так что просмотренное на них может не сохраниться. Реши до того, как начнёшь смотреть.
- **Показаны только каталоги фильмов, сериалов и каналов**, и только те, которым не нужен поиск или сначала выбор жанра.
- **Прямые эфиры** нельзя поставить на паузу с далёкого места, продолжить позже или отметить как просмотренные. Они работают только в приложениях, которые просят rex их конвертировать (приложения Plex и Plezy; Plex Web не проверялся). Каналы без рабочего потока или с DRM в список не попадают.
- **Любой, кто может достучаться до адреса rex-stremio, может играть через него.** Оставь `127.0.0.1`, если только rex не работает на другом компьютере.

В README перечислены [остальные ограничения](https://github.com/debridmediamanager/rex-stremio#limits) и каждая настройка в `config.json`. Чтобы написать собственный аддон, см. [Создание аддонов для rex](addons.md). Там же объясняется, как устроен rex-stremio внутри.
