# rex

[rex](https://rex.debridmediamanager.com/ru/) — это медиасервер для официальных приложений Plex, который не хранит никаких файлов. Источник сообщает ему, что есть в вашей библиотеке, и отдаёт каждый файл. rex запускает потоковую передачу файла, когда вы нажимаете «воспроизвести». rex бесплатен для личного использования. Его [исходный код](https://github.com/debridmediamanager/rex) открыт по лицензии PolyForm Noncommercial. Он работает на Linux, macOS и Windows, а также как Docker-образ для Linux `ghcr.io/debridmediamanager/rex:nightly` ([со своим приложением](any-source.md#run-rex-in-docker), [с zurg](with-zurg.md#run-rex-in-docker)).
