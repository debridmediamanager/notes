# rex

[rex](https://rex.debridmediamanager.com/ru/) — це медіасервер для офіційних застосунків Plex, який не зберігає жодних файлів. Джерело повідомляє rex, що є у вашій бібліотеці, і віддає кожен файл. rex передає потік цього файлу, коли ви натискаєте відтворення. rex безкоштовний для особистого використання. Його [вихідний код](https://github.com/debridmediamanager/rex) відкритий за ліцензією PolyForm Noncommercial. Він працює на Linux, macOS і Windows, а також як Docker-образ для Linux `ghcr.io/debridmediamanager/rex:nightly` ([з вашим застосунком](any-source.md#run-rex-in-docker), [з zurg](with-zurg.md#run-rex-in-docker)).
