# rex

[rex](https://rex.debridmediamanager.com/ru/) — це медіасервер для офіційних застосунків Plex, який не зберігає жодних файлів. Джерело повідомляє йому, що є у вашій бібліотеці, і віддає кожен файл. rex передає потік цього файлу, коли ви натискаєте play. rex безкоштовний для особистого використання. Його [вихідний код](https://github.com/debridmediamanager/rex) відкритий за ліцензією PolyForm Noncommercial. Працює на Linux, macOS і Windows, а також як Docker-образ для Linux `ghcr.io/debridmediamanager/rex:nightly` ([з вашим власним застосунком](any-source.md#run-rex-in-docker), [з zurg](with-zurg.md#run-rex-in-docker)).
