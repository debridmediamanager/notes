# What a sponsorship gives you

DMM is free for everyone and stays free. A sponsorship pays its hosting and keeps zurg and rex in development. This page lists everything it opens and where each thing is set up.

Sponsor on [gatekeeper](https://gatekeeper.debridmediamanager.com/). It shows your DMM API key once you sign in. Its **Open DMM with this key** link turns the DMM perks on in that browser. Everything else takes the same key in its own settings. Keep the key private because it works like a password.

The perks follow the sponsorship. When it ends they stop on the next request. Pressing **Reset key** on gatekeeper stops the old key everywhere at once.

## zurg

| What you get | Where |
|---|---|
| Nightly builds with every provider and Usenet plus the Docker image and the Android app | [zurg setup](../zurg/setup/index.md) after you accept the GitHub invitation |
| The full zurg source code | The private repository on GitHub |
| Every release named for rex and Plex | `dmm_api_key` in the [zurg config](../zurg/reference/config.md) |
| The `__magic__` folders sorted for you | [\_\_magic\_\_](../zurg/guides/magic.md) |
| Your DMM wanted list fetched by zurg | [DMM wanted list](../zurg/guides/dmm-wanted.md) |
| Usenet copies with missing parts reported so DMM hands out a working copy first | Nothing to set up once `dmm_api_key` is set |

## rex

rex is free and needs no sponsorship. With a key [rex-stremio](../rex/stremio.md) starts streams DMM already knows without probing them first. Set `dmm_api_key` in its config.

## Earn it without paying

Fill requests on DMM's [request board](https://debridmediamanager.com/requests). Every 10 requests you fill earn 7 days of the DMM perks above. Link the key from a free gatekeeper account on the board to collect them. Earned time covers DMM and the DMM key in zurg. The zurg nightly and source code still need a paid sponsorship.

Stuck? Ask in the **dmm-support** forum on [Discord](https://discord.com/invite/7u4YjMThXP).
