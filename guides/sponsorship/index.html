What a sponsorship gives you

DMM is free. Sponsorships pay for its hosting and keep zurg and rex moving. This page lists every perk and where to set it up.

Sponsor on gatekeeper. Sign in there to see your DMM API key. Open DMM with this key links it in that browser. Add the same key in the other services that ask for it. Keep it private because it works like a password.

Perks follow the sponsorship. When it ends DMM stops them on the next request. Gatekeeper revokes zurg access and the Discord role on its next check. Reset key stops the old key everywhere at once.

rex

rex is free and needs no sponsorship. With a key rex-stremio adds titles DMM already knows in seconds instead of probing each one. Paste it in rex-stremio's DMM field. It shares its own probes with DMM unless you turn that off.

Earn it without paying

Fill requests on DMM's request board. Every 10 requests earn 7 days of the DMM perks above. Only one fill for the same person each day counts. Link the key from a free gatekeeper account on the board to collect them.

Earned time opens the DMM table above. It does not open the zurg nightly or source code or Discord role or remote help. Those need a paid sponsorship. The dmm_api_key features also need a nightly.

Stuck? Ask in the dmm-support forum on Discord.
